# デスクトップ版の使い方（Windows）

MFRM Desktopは、作文や実技などの評定データを読み込み、対象者・評価者・課題などの違いを図と表で確認するアプリです。このページでは、初めて使う方に向けて、起動から結果の保存までを説明します。

現在のデスクトップ版は、共通の評定尺度を使うRSMをJMLEで推定します。FACETSやConQuestのインストールは不要です。Web版にある分析機能がすべて使えるわけではありません。

## 入手と起動

**2026年10月29日時点では、Windows用EXEの一般配布はまだ行っていません。** [GitHub Releases](https://github.com/Ryuya-dot-com/MFRM_Python_Application/releases)にソースコードのZIPがあっても、それはインストーラーではありません。現在は、次の手順でソースコードから起動できます。

Pythonの準備をせずに試す場合は、[Web版](https://mfrmpythonapplication-xodghmcghngx8cz5zmhfeg.streamlit.app)を利用してください。Web版の操作は[作文サンプルのガイド](apa_manuscript_template.md#writing-assessment-first-report)を参照してください。

### Pythonから起動する

この手順の対象はWindowsです。Windows 11とPython 3.12で動作を確認しています。

1. Python 3.12の環境を用意します（[Python公式サイト](https://www.python.org/downloads/windows/)）。Tkinterを含むWindows用Pythonが必要です。
2. [リポジトリのトップページ](https://github.com/Ryuya-dot-com/MFRM_Python_Application)で **Code → Download ZIP** を選び、ダウンロードしたZIPを展開します。
3. 展開した中の `desktop_app.py` と `requirements.txt` があるフォルダーを開き、そのフォルダーでPowerShellを開きます。
4. 次のコマンドを1行ずつ実行します。初回のインストールにはインターネット接続が必要です。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe desktop_app.py
```

アプリのウィンドウが開いたら、下の「サンプルで試す」に進みます。使用中は起動に使ったPowerShellを開いたままにしてください。

2回目以降は、同じフォルダーで最後のコマンドだけを実行します。

```powershell
.\.venv\Scripts\python.exe desktop_app.py
```

デスクトップ版の通常の分析・図表表示・保存は、パソコン内で行います。アプリ内の「Web版の理論・ヘルプ」を開くときはインターネット接続が必要です。

## サンプルで試す

1. 「データ」画面で **サンプル** を押します。作文の人工データが表示されます。
2. **次へ** を押します。
3. 「設定」で、次の内容を確認します。サンプルを選ぶと、これらの値が設定されます。

| 項目 | サンプルの設定 |
|---|---|
| 対象者 | `Person` |
| 得点 | `Score` |
| 評価者・課題など | `Rater`、`Task`、`Criterion` |
| 最低点・最高点 | `0`・`5` |

4. **分析** を押します。計算が終わると「結果」画面に切り替わります。
5. 「図」の選択欄で **Wright map**、**Pathway map**、**確率曲線** を切り替えます。図の説明は **読み方** で開けます。
6. 「推定値」「得点」「データ概要」のタブを開いて表を確認します。
7. **プロジェクトを保存** を押し、練習用の名前で保存します。

![作文の人工データを分析し、Pathway mapを表示した画面](images/desktop-pathway.png)

この画面は人工データの表示例です。Pathway mapでは、図の横にある選択欄で評価者・課題・観点などを切り替えられます。

## 自分のCSVを使う

### データの形

**1行を「1人に対する、1人の評価者による、1つの課題・観点の評定」にします。** 同じ対象者に複数の評定がある場合は、行を分けます。

```csv
Person,Rater,Task,Criterion,Score
E01,R1,Task1,Content,4
E01,R1,Task1,Organization,3
E01,R2,Task1,Content,5
E02,R1,Task1,Content,2
```

上は形式を示す抜粋です。分析用のデータ一式には、[作文の見本CSV](../examples/desktop_writing.csv)を利用してください。アプリの **CSV形式 → 見本CSVを保存** からも保存できます。

| 列の例 | 入れる内容 |
|---|---|
| `Person` | 受験者・学習者などのID。同じ人には同じIDを使います。 |
| `Rater` | 評価者のID。 |
| `Task` | 課題のID。 |
| `Criterion` | 内容・構成などの評価観点。 |
| `Score` | その1回の評定の整数得点。平均点や合計点にはしません。 |

列名は日本語でも構いません。課題・観点の列は、実際の評価設計にあるものを用意します。

- Excelからは **CSV UTF-8（コンマ区切り）** で保存します。
- 未採点は0点にせず、行を作らないか、得点を空欄にします。0点は実際に0点を付けた評定として扱われます。
- 評価者ごとに得点の列が並んでいる場合は、上の見本のように評価者IDと得点を行に分けます。
- 同じ対象者・評価者・課題・観点の組合せが重複していないか確認します。再採点を区別する場合は、採点回などの列も必要です。

### 読み込みと設定

1. **CSVを開く** でファイルを選び、先頭10行のプレビューで列と値を確認します。
2. **次へ** を押し、「対象者」と「得点」の列を選びます。
3. 「評価者・課題など」で分析する列をクリックして選択します。複数選択できます。同じ列を対象者・得点と重ねて指定することはできません。
4. 採点基準の「最低点」「最高点」を入力します。例えば基準が0〜5点なら、今回0点がなくても最低点は `0` です。
5. **分析** を押します。対象外の行や重複について確認画面が出た場合は、行数と理由を確認してから続行します。

空欄・文字などの得点は計算対象から外れます。小数、無限大、採点基準の範囲外の得点は修正が必要です。この版では各評定を等しく扱い、重み列を追加しても重み付き分析にはなりません。

## 結果を読む

最初に「データ概要」で分析対象を確認し、画面に警告がないか確認します。

| 表示 | 確認すること |
|---|---|
| Wright map | 対象者の測定値の分布と、評価者・課題などの位置。通常の設定では、上ほど評価者は厳しく、課題は難しくなります。 |
| Pathway map | 縦軸の測定値と横軸の適合度。最初は `Infit MnSq` が表示されます。1からの隔たりだけで良否を決めず、評定数や元の評定も確認します。 |
| 確率曲線 | どの得点カテゴリーが、どの範囲で選ばれやすいか。カテゴリーの使用頻度や採点基準と合わせて読みます。 |
| 推定値 | 対象者・評価者・課題などの測定値と適合度。表の「注記」も確認します。 |
| 得点 | 得点カテゴリーが実際に何回使われたか。 |

図の **読み方** と表の **注記** に、その出力の説明があります。点の位置や適合度だけから、評価の妥当性や差の有無を結論づけないでください。

「推論は保留です」と表示される場合は、下の「困ったとき」を参照してください。図が表示されることと、その結果を統計的な判断に使えることは別です。

## 保存する

| 目的 | 操作・保存形式 |
|---|---|
| 後で分析を開き直す | **プロジェクトを保存** → `.mfrm`。入力データ、設定、結果を保存します。 |
| 図と表をまとめて読む・共有する | **レポートを保存** → `.html`。保存したファイルをブラウザーで開きます。 |
| 図を文書やスライドに使う | 表示したい図を選び、**図を保存…** → `.png` または `.svg`。 |

保存した分析は、「データ」画面の **プロジェクトを開く** から `.mfrm` を選ぶと、再計算せずに開けます。HTMLや画像からは分析を復元できないので、続きの作業をする場合はプロジェクトも保存してください。

プロジェクトには入力データと対象者・評価者のIDも含まれます。共有する場合は、共有してよいデータか確認してください。

設定を変更しても、表示済みの結果は自動で再計算されません。「前回の分析」の表示がある場合は、設定を確認して **分析** を押し直します。残したい結果は先に別名で保存してください。

## 困ったとき

| 状況 | 確認・対応 |
|---|---|
| `py -3.12` が実行できない | Python 3.12が利用できるか確認します。用意が難しい場合はWeb版から試してください。 |
| CSVを読み込めない・文字化けする | Excelで「CSV UTF-8（コンマ区切り）」として保存し直します。1行目の列名が空欄・重複になっていないかも確認します。 |
| 「分析」を押しても設定画面にとどまる | 画面のメッセージに従い、列の指定、最低点・最高点、得点の値を確認します。 |
| 計算対象の行数が少ない | 得点や必要なIDの空欄など、分析前の確認画面で示された対象外の行を確認します。 |
| 「推論は保留です」と表示される | 表示された理由を読みます。評価者や課題に共通の対象者がいるか、評定が最低点・最高点に偏っていないか、計算が正常に終了したかを確認します。保留中の結果から差や順位を結論づけないでください。 |
| 表のSE（標準誤差）などが空欄になっている | 表の「注記」と保留の表示を確認します。空欄を0や「誤差なし」と扱わないでください。 |
| 設定を変更しても図が変わらない | 表示中の結果は前回の分析です。新しい設定で「分析」を押し直します。 |
| 計算を止めたい | 計算中に表示される「中止」を押します。 |

解決しない場合は、[GitHub Issues](https://github.com/Ryuya-dot-com/MFRM_Python_Application/issues)に、OS、ウィンドウのタイトルに表示されるバージョン、操作手順、エラーメッセージを記載してください。画面やCSVを添える場合は、個人を特定できる情報を除いてください。

より詳しい理論は、アプリの **ヘルプ → Web版の理論・ヘルプ** からWeb版のHelp／Tutorialを参照できます。
