# デスクトップ版の使い方（macOS・Windows）

MFRM Desktopは、作文や実技などの評定データを読み込み、対象者・評価者・課題などの違いを図と表で確認するアプリです。このページでは、初めて使う方に向けて、起動から結果の保存までを説明します。

デスクトップ版はRSM／PCM、JMLE／固定母集団SDのMML、バイアス分析、指定区間・共同交互作用、G/D Studyを備えています。初回の配布物にこれらをまとめて含めます。FACETSやConQuestのインストールは不要です。対応する設計と推論の条件は下の「分析を選ぶ」と各出力の注記で確認してください。

画面は英語で始まります。上部の言語欄で **日本語** に切り替えると、このページのボタン名に合わせて操作できます。入力した列名・水準名は翻訳しません。

## 入手と起動

アプリZIPは[macOSデスクトップ試用版のRelease](https://github.com/Ryuya-dot-com/MFRM_Python_Application/releases/tag/desktop-macos-20261030)または[Windowsデスクトップ試用版のRelease](https://github.com/Ryuya-dot-com/MFRM_Python_Application/releases/tag/desktop-windows-20261030)から取得できます。各Releaseにダウンロード先とSHA-256を記載しています。Pythonは同梱されており、追加インストールは不要です。GitHubの自動生成ソースZIPや別のv0.2.19-beta Web版Releaseは、デスクトップアプリのダウンロードではありません。

試用版の対象は **macOS（Apple Silicon / M1以降、同梱ライブラリ下限 macOS 14.0）** および **Windows 11 x64** です。Intel MacやWindows on ARMは対象外です。確認した環境と未確認の範囲は各Releaseに記載しています。すべてのOS構成に対応を認定した安定版ではありません。

### macOSでアプリZIPから起動する

1. [macOS試用版のRelease](https://github.com/Ryuya-dot-com/MFRM_Python_Application/releases/tag/desktop-macos-20261030)からアプリZIPを取得し、開く前にターミナルの `shasum -a 256` でSHA-256の一致を確認します。
2. FinderでZIPをダブルクリックして展開し、`MFRM-Desktop.app` 全体を書き込み可能な場所（自分の `Applications` フォルダーなど）へ置きます。
3. アプリを開きます。試用版はApple Developer IDの公証を受けていません。開発元未確認の警告が出る場合は、[Appleの案内](https://support.apple.com/ja-jp/102445)に従い、入手元とSHA-256を確認した上で端末の設定が許す場合に限り **システム設定 → プライバシーとセキュリティ → このまま開く** を使用してください。Gatekeeper全体の無効化や隔離属性の削除は行わないでください。

### WindowsでアプリZIPから起動する

1. 案内された同一版のZIPとSHA-256を入手します。
2. エクスプローラーの **すべて展開** で展開し、`MFRM-Desktop.exe` と `_internal` を同じフォルダーに保持します。
3. EXEを開きます。ZIP内から直接実行したり、EXEだけ移動したりしないでください。
4. 下のサンプルで操作を試します。

試用版は未署名です。Windowsの保護機能により起動が止まる場合は、表示されたメッセージをそのまま記録して問い合わせてください。起動のためにWindows全体の保護を無効にしないでください。

アプリZIPを持っていない場合は、インストール不要の[Web版](https://mfrmpythonapplication-xodghmcghngx8cz5zmhfeg.streamlit.app)から試せます。[作文サンプルのガイド](apa_manuscript_template.md#writing-assessment-first-report)を参照してください。ソースコードから起動する場合だけ、[開発者向け起動手順（英語）](../CONTRIBUTING.md#run-from-source)を使います。ブランチや版によって含まれる機能が異なります。

デスクトップ版の通常の分析・図表表示・保存は、パソコン内で行います。アカウントは不要です。アプリ内の「Web版の理論・ヘルプ」を開くときはインターネット接続が必要ですが、その操作で入力データや結果をアップロードすることはありません。

## サンプルで試す

1. 「データ」画面で **サンプル** を押します。作文の人工データが表示されます。
2. **次へ** を押します。
3. 「設定」で、次の内容を確認します。サンプルを選ぶと、これらの値が設定されます。

| 項目 | サンプルの設定 |
|---|---|
| 対象者 | `Person` |
| 得点 | `Score` |
| 評価者・課題など | `Rater`、`Task`、`Criterion` |
| 最低点・最高点 | `0`・`5` |

4. **分析** を押します。計算が終わると「結果」画面に切り替わります。
5. 「図」の選択欄で **Wright map**、**Pathway map**、**カテゴリー確率** を切り替えます。図の説明は **読み方** で開けます。
6. 「表」の選択欄で推定値・得点などを選び、「データ概要」も確認します。
7. **プロジェクトを保存** を押し、練習用の名前で保存します。

Pathway mapでは、図の横にある選択欄で評価者・課題・観点などを切り替えられます。

## 自分のCSVを使う

### データの形

**1行を「1人に対する、1人の評価者による、1つの課題・観点の評定」にします。** 同じ対象者に複数の評定がある場合は、行を分けます。

```csv
Person,Rater,Task,Criterion,Score
E01,R1,Task1,Content,4
E01,R1,Task1,Organization,3
E01,R2,Task1,Content,5
E02,R1,Task1,Content,2
```

上は形式を示す抜粋です。分析用のデータ一式には、[作文の見本CSV](../examples/desktop_writing.csv)を利用してください。アプリの **CSV形式 → 見本CSVを保存** からも保存できます。

| 列の例 | 入れる内容 |
|---|---|
| `Person` | 受験者・学習者などのID。同じ人には同じIDを使います。 |
| `Rater` | 評価者のID。 |
| `Task` | 課題のID。 |
| `Criterion` | 内容・構成などの評価観点。 |
| `Score` | その1回の評定の整数得点。平均点や合計点にはしません。 |

列名は日本語でも構いません。課題・観点の列は、実際の評価設計にあるものを用意します。

- Excelからは **CSV UTF-8（コンマ区切り）** で保存します。
- 未採点は0点にせず、行を作らないか、得点を空欄にします。0点は実際に0点を付けた評定として扱われます。
- 評価者ごとに得点の列が並んでいる場合は、上の見本のように評価者IDと得点を行に分けます。
- 同じ対象者・評価者・課題・観点の組合せが重複していないか確認します。再採点を区別する場合は、採点回などの列も必要です。

### 読み込みと設定

1. **CSVを開く** でファイルを選び、先頭10行のプレビューで列と値を確認します。
2. **次へ** を押し、「対象者」と「得点」の列を選びます。
3. 「評価者・課題など」で分析する列をクリックして選択します。複数選択できます。同じ列を対象者・得点と重ねて指定することはできません。
4. 採点基準の「最低点」「最高点」を入力します。例えば基準が0〜5点なら、今回0点がなくても最低点は `0` です。
5. **分析** を押します。対象外の行や重複について確認画面が出た場合は、行数と理由を確認してから続行します。

空欄・文字などの得点は計算対象から外れます。小数、無限大、採点基準の範囲外の得点は修正が必要です。この版では各評定を等しく扱い、重み列を追加しても重み付き分析にはなりません。

## 分析を選ぶ

「設定」の入口で **MFRM** または **G/D Study** を選びます。MFRMでは「列・採点基準」「モデル・推定」「バイアス・区間」「G/D計画」の各タブを使います。

| 目的 | 設定と対象 |
|---|---|
| 共通のカテゴリー段階を使う | **RSM**。JMLEまたは固定SD MMLを選びます。 |
| 要因の水準ごとにカテゴリー段階を変える | **PCM** と段階を分けるファセットを選びます。JMLE／固定SD MMLに対応します。 |
| 固定母集団SDで周辺推定する | **MML**。EMによる推定で、求積点数と固定SDを指定します。SD自体の推定ではありません。 |
| 特定の要因の組合せを診断する | 「バイアス・区間」で要因対を**追加**します。固定較正の条件付き診断は、バイアスの有無や有意性を確定する検定ではありません。 |
| 水準または事前指定差の区間を見る | 固定SD MMLで「指定区間」を追加します。数値条件を満たす対象だけに点ごとの近似区間を表示し、保留理由を保持します。 |
| 主効果と交互作用を一緒に推定する | 「共同交互作用」で一つの要因対と対象セル・差を指定します。固定N(0,1)のRSM／PCMを別モデルとして再推定し、近似区間・Wald p値とHolm補正を表示します。補正は区間には適用しません。 |
| 評定者数・課題数による信頼性の変化を見る | G/D Studyで測定対象・得点・1～2ランダム要因と計画水準数を指定します。完全均衡交差・各セル1観測・単位重みの範囲です。MFRMと別の入口でも、MFRMと同時でも実行できます。 |

G/Dは元の観測得点を使い、相対評価のGと絶対評価のPhiを区別します。対象母集団は利用者が指定します。G/Dの区間と多変量G/Dは未実装です。指定区間や共同交互作用の数値条件を満たすことは、有限標本での被覆率保証ではありません。

バイアス・指定区間は、欄を入力しただけでは登録されません。**追加**を押し、一覧に表示された条件を確認してください。共同交互作用では、MML・固定SD `1` を選び、「次回の分析に追加」を有効にします。元の主効果モデルと固定較正の診断も保持されます。

G/Dは各要因に2水準以上が必要です。負の分散成分は元の符号付きの値を表に残し、係数の計算では0として扱います。指定区間・共同交互作用の近似推論は、独立な対象者、指定した応答モデル・正規母集団、無視可能な割当て・欠測、識別可能で境界上にないパラメーターなどを仮定します。[適用範囲の詳しい説明（英語）](analysis_scope.md)も参照してください。

## 結果を読む

最初に「データ概要」で分析対象を確認し、画面に警告がないか確認します。

| 表示 | 確認すること |
|---|---|
| Wright map | 対象者の測定値の分布と、評価者・課題などの位置。通常の設定では、上ほど評価者は厳しく、課題は難しくなります。 |
| Pathway map | 縦軸の測定値と横軸の適合度。最初は `Infit MnSq` が表示されます。1からの隔たりだけで良否を決めず、評定数や元の評定も確認します。 |
| カテゴリー確率 | どの得点カテゴリーが、どの範囲で選ばれやすいか。カテゴリーの使用頻度や採点基準と合わせて読みます。 |
| 推定値 | 対象者・評価者・課題などの測定値と適合度。表の「注記」も確認します。 |
| 得点 | 得点カテゴリーが実際に何回使われたか。 |

図の **読み方** と表の **注記** に、その出力の説明があります。点の位置や適合度だけから、評価の妥当性や差の有無を結論づけないでください。

一般MML表や個人得点の不確実性には、推論への利用制限があります。一方、専用の指定区間・共同交互作用は、各出力の条件に従って利用可否を判断します。全体の注意表示だけで、専用出力まで一括して利用不可とは解釈しないでください。図が表示されること自体も、推論が可能であることを意味しません。

## 保存する

| 目的 | 操作・保存形式 |
|---|---|
| 後で分析を開き直す | **プロジェクトを保存** → `.mfrm`。入力データ、設定、結果を保存します。 |
| 図と表をまとめて読む・共有する | **レポートを保存** → `.html`。保存したファイルをブラウザーで開きます。 |
| 図を文書やスライドに使う | 表示したい図を選び、**図を保存…** → `.png` または `.svg`。 |
| 表を他のソフトで使う | 表を選んでCSV保存。出力の利用条件・注記も保持します。 |

図の「説明付き／論文掲載用」を切り替えられます。論文掲載用では全体タイトルと長い説明注を図外へ分離し、軸・凡例・水準名を保持します。「タイトル・図注」で文をコピーできます。PNG／SVGと一緒に保存する `.caption.txt` の内容を論文の図注へ反映してください。この切替だけで、APAや投稿先の全要件を満たすわけではありません。

保存した分析は、「データ」画面の **プロジェクトを開く** から `.mfrm` を選ぶと、再計算せずに開けます。HTMLや画像からは分析を復元できないので、続きの作業をする場合はプロジェクトも保存してください。

この試用版は以前の基本分析のプロジェクトも読み込めますが、この版で保存した拡張形式を旧アプリで開くことはできません。更新時は旧アプリと元のプロジェクトを残し、新しいアプリを別フォルダーへ展開して、プロジェクトのコピーを開いてください。同じバージョン表示でも試用版のビルドが異なる場合があるため、配布ZIP名も控えておきます。

WindowsのZIP版は `.mfrm` の標準アプリを自動登録しません。ダブルクリックでアプリの選択を求められた場合も、本体を先に起動して **データ → プロジェクトを開く** から選べます。

プロジェクトには入力データと対象者・評価者のIDも含まれます。共有する場合は、共有してよいデータか確認してください。

設定を変更しても、表示済みの結果は自動で再計算されません。「前回の分析」の表示がある場合は、設定を確認して **分析** を押し直します。残したい結果は先に別名で保存してください。

## 困ったとき

| 状況 | 確認・対応 |
|---|---|
| EXEが起動しない | ZIP全体を展開したか、`_internal` が同じ場所にあるか、Windowsがx64か確認します。保護機能で止まる場合はメッセージを記録します。 |
| CSVを読み込めない・文字化けする | Excelで「CSV UTF-8（コンマ区切り）」として保存し直します。1行目の列名が空欄・重複になっていないかも確認します。 |
| 「分析」を押しても設定画面にとどまる | 画面のメッセージに従い、列の指定、最低点・最高点、得点の値を確認します。 |
| 計算対象の行数が少ない | 得点や必要なIDの空欄など、分析前の確認画面で示された対象外の行を確認します。 |
| 入力・設計や数値条件が理由で区間を表示できない | 該当出力の理由を読みます。列の指定、共通の対象者による接続、極端得点、推定の終了状態など、指摘された条件を確認します。図の点や推定値だけから差・順位を確定しないでください。 |
| 方法の未対応・検証範囲が理由で推論を利用できない | 一般MML表、個人得点の不確実性、G/D区間などの制限は、入力を変更したり同じ分析を再実行したりしても解消しません。利用可能な専用出力とその条件を確認します。 |
| 表のSE（標準誤差）などが空欄になっている | 表の「注記」と保留の表示を確認します。空欄を0や「誤差なし」と扱わないでください。 |
| 設定を変更しても図が変わらない | 表示中の結果は前回の分析です。新しい設定で「分析」を押し直します。 |
| 計算を止めたい | 計算中に表示される「中止」を押します。 |

解決しない場合は、[GitHub Issues](https://github.com/Ryuya-dot-com/MFRM_Python_Application/issues)に、OS、ウィンドウのタイトルに表示されるバージョン、操作手順、エラーメッセージを記載してください。画面やCSVを添える場合は、個人を特定できる情報を除いてください。

より詳しい理論は、アプリの **ヘルプ → Web版の理論・ヘルプ** からWeb版のHelp／Tutorialを参照できます。
