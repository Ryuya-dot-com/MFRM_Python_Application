## 2026-10-09: 条件付きバイアス推定の固定配列と一括演算

PCM/GPCMの各セルで、固定された段階母数の所属行、得点、重み、傾きの配列を
1回だけ準備し、スカラーのシフトを探索するときの確率・正規化計算を一括で行う。
`streamlit_app.py` の `_prepare_bias_cell_functions` はセルごとに作り直す。
較正値やPerson値が変わる別の呼び出しとはキャッシュを共有しない。

各観測の対数分子は従来と同じ `a_i * ((eta_i + b) * k - cumulative_step_ik)`
（PCMでは傾き1）で評価する。尤度は元の段階母数グループの順序で、
各グループ内も元の行順序で合計する。探索法・許容誤差・区間のカットオフ・
重みの適格性・失敗状態・多重性の分母・公開上の資格保留は維持する。
