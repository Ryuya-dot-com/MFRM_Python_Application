## 問題と修正範囲

統合ブランチの自由分散MMLは、他の推定パラメータを固定して母集団SDの
対数尤度を数値微分し、その値を「Profile SE」として表示していた。
さらに、その値から正規近似の95%信頼区間を作成していた。
これはプロファイル尤度の曲率ではなく、「やや楽観的」と誤差の程度を
保証することもできない。保存済み結果の再表示と論文用出力にも影響する。

今回、点推定アルゴリズムは維持し、不確実性の計算・表示・出力契約を修正した。

| 対象 | 修正後 |
| --- | --- |
| 推定SD | 技術的な点推定値として保持 |
| 他パラメータ固定の曲率 | `population_sd_conditional_curvature_scale` に技術診断値として保持 |
| `population_sd_se` / `population_sd_ci` | 新規推定では `None`。通常のSE・信頼区間を生成しない |
| 日英UI・方法付録・論文用案内 | SE・信頼区間の保留と根拠を表示。古い保存結果の数値も推論用に再表示しない |
| 出力資格表 | `mml.population_sd_uncertainty` を `WITHHELD`、`PublicConclusionAllowed=False` とする |
| 数値微分 | 差分点がSDの上下限に触れる場合、非有限値や非正の情報量の場合は診断値も利用不可 |

技術出力に残る旧設定値や曲率診断値は、公開結論への利用を認めるものではない。
保存された資格フラグによって現在の保留を解除することもできない。

## 数学的根拠

SDを σ、他の自由パラメータを β とする。プロファイル対数尤度は

\[
\ell_p(\sigma)=\max_\beta\ell(\beta,\sigma)
\]

であり、σを動かすごとにβも再最適化する。
[Rのプロファイル実装](https://svn.r-project.org/R/trunk/src/library/stats/R/glm-profile.R)
でも、対象係数を固定した各点で残りの係数を再推定している。

内点の停留解で観測情報行列が正定値である等の正則条件の下では、局所的な
プロファイル情報はSchur補行列

\[
I_p=I_{\sigma\sigma}
 - I_{\sigma\beta}I_{\beta\beta}^{-1}I_{\beta\sigma}
\]

となる。旧コードの値は \(1/\sqrt{I_{\sigma\sigma}}\) に対応し、
他のパラメータとの結合項を含まない。両者の一致は一般には保証されない。
また、局所曲率からのWald区間と、尤度比を反転したプロファイル尤度区間は別物である。

解析的な反例として、\(x=\sigma-1.5\) とおき、

\[
\ell(\beta,\sigma)=-\tfrac12(\beta^2+2\rho\beta x+x^2),
\qquad \rho=0.99
\]

を考える。βを0に固定すると曲率スケールは1。βを \(-\rho x\) に再最適化すると
\(1/\sqrt{1-\rho^2}\approx7.0888\) となる。これはアプリの実データで誤差が
7倍だったという主張ではなく、誤差を「わずか」とする一般的な根拠がないことの証明である。
現在のEM解が上記の正則条件を満たすとの認定も行っていない。

### GPCMの情報量

アプリの内部得点を \(k\)、識別力を \(a_i\)、加法的な位置を \(\eta_i\)、
累積ステップを \(T_{ik}\) とすると、使用する確率は

\[
p_i(k)=\frac{\exp\{a_i(k\eta_i-T_{ik})\}}
 {\sum_h\exp\{a_i(h\eta_i-T_{ih})\}}.
\]

他のパラメータを固定して直接微分すると

\[
\frac{\partial\log p_i(k)}{\partial\eta_i}
=a_i\{k-E_i(K)\},\qquad
-\frac{\partial^2\log p_i(k)}{\partial\eta_i^2}
=a_i^2\operatorname{Var}_i(K).
\]

したがって、重み付き目的関数に対する位置の曲率は
\(I=\sum_i w_i a_i^2\operatorname{Var}_i(K)\)、条件付き近似SEは
\(I^{-1/2}\) となる。ファセットの向きが±1でも二乗されるため同じであり、
\(a_i=1\) ではRaschの式へ戻る。これは尤度からの直接導出である。
GPCMの情報関数の原論文の書誌は
[Muraki (1993), ETS RR-93-27](https://www.ets.org/research/policy_research_reports/publications/report/1993/ihfu.html)
を参照（今回参照したETSページは書誌・要旨）。

重み付き曲率が任意の標本設計での標本分散になるとの主張はしない。
このSEは他の推定値、同定制約、アンカーの不確実性を共同伝播したSEでもない。
MMLのPerson事後SDおよび共分散を使う構造SEとは、従来どおり区別する。

### 共分散の対象とデルタ法

構造パラメータをβ、\(s=\log\sigma\) とする。内点の停留解と正定値の共同情報行列
などの正則条件の下で、βの共分散ブロックは

\[
(I^{-1})_{\beta\beta}
=\{I_{\beta\beta}-I_{\beta s}I_{ss}^{-1}I_{s\beta}\}^{-1}.
\]

現在の構造Hessianの逆行列 \(I_{\beta\beta}^{-1}\) は、sを固定した値である。
σ自体のSEを保留するだけでは、βの不確実性の欠落は解決しない。
今回、共同共分散や被覆率を新たに認定せず、この適用外の計算を保留した。

正則化についても、\(Q=-\ell+P\) のHessianの逆行列は、通常の尤度情報の
逆行列と区別する。例えば \(Y\sim N(\beta,1)\)、\(P=\lambda\beta^2/2\) では、
推定量は \(Y/(1+\lambda)\)、その標本分散は \((1+\lambda)^{-2}\) だが、
曲率の逆数は \((1+\lambda)^{-1}\) である。後者は対応する正規事前分布の下では
事後分散になるが、標本分散と同一ではない。ペナルティの値がゼロとなる点でも
曲率は残るため、ペナルティ値の大小ではなく設定の有効状態で判定する。

デルタ法の分散は \(g^T\Sigma g\)。計算不能な成分は既知のゼロ微分ではないため、
全成分を取得できなければSE・区間を生成しない。固定値のように全微分がゼロと
計算できる場合はSE=0を維持する。

### MMLの観測情報とEMのM-stepを区別する

有限個の能力点について \(m_j(\beta)=\sum_q w_q L_{jq}(\beta)\)、
\(r_{jq}=w_qL_{jq}/m_j\)、\(s_{jq}=\nabla_\beta\log L_{jq}\)、
\(J_{jq}=-\nabla_\beta^2\log L_{jq}\) とおく。和を直接微分すると

\[
\nabla_\beta\log m_j=E_{r_j}(s_{jq}),\qquad
-\nabla_\beta^2\log m_j=E_{r_j}(J_{jq})-
 \operatorname{Cov}_{r_j}(s_{jq}).
\]

EMのM-stepで事後重みを固定した曲率は第1項だけである。能力を積分した観測情報には
第2項の減算が必要となる。停留点以外でも成立するため、共分散項には未中心化の二次
モーメントではなく、スコアの事後平均を引いた共分散を使う。

新しい `tests/test_mml_information_identity.py` は、3点の有限混合を明示的に列挙し、

### 修正したPosteriorMAPGridとEAPの説明

`compute_person_posterior_outputs` の従来の `PosteriorMAPGrid` は
\(\arg\max_q\{w_qL(\theta_q)\}\) を返していた。Gauss–Hermiteの \(w_q\) は
求積重みなので、これは事後密度の最大点とは一般に一致しない。
正規母集団 \(N(\mu,\sigma^2)\) の下で、修正後は

\[
\arg\max_{\theta_q}\left\{\log L(\theta_q)
-\frac{(\theta_q-\mu)^2}{2\sigma^2}\right\}
\]

を返す。積分点上の密度最大点であり、連続尺度上のMAPを計算したとは表示しない。
EAP・事後SD・分位点・plausible valuesには従来どおり正規化した求積質量を使う。
既に保存済みの結果に含まれる旧MAPGrid値は自動変換していない。比較・報告に使う場合は、
修正後の関数で事後得点を再計算する必要がある。

反例は、二値反応の成功4・失敗1、事前SD=0.7、GH5、項目位置=母集団平均μである。
旧出力はμ+0.94893832598、積分点上の密度最大点はμとなる。μ=0と1.25、RSM・PCM・
傾き1のGPCMで同じ不整合を修正前に再現した。このμという値は連続尺度上のMAPではない。
修正は求積点数の増加や最適化器の変更ではなく、最大化する数学的対象の訂正である。

あわせて、PersonのSEを「EAP推定量のSE」と読める説明から、校正・母集団パラメータを
固定した潜在能力の事後SDへ明確化した。結果表の対称区間も、EAP±z×条件付き事後SDの
正規近似であり、事後分位点の区間や校正誤差を伝播した区間ではないと明記した。

### 符号と分散の直接導出

対象の主効果を \(m\)、線形予測子内の係数を \(s\in\{-1,+1\}\) とする。
現行セル推定器の `Bias Size` は \(\eta+b_c\) の加算項である。したがって
対象尺度上の局所値 \(L_c\) は

\[
sL_c=sm+b_c,\qquad L_c=m+b_c/s,
\qquad \Delta=L_1-L_2=(b_1-b_2)/s.
\]

Personは \(s=+1\)、既定の厳しさ尺度は \(s=-1\)。任意の正方向facetも設定の符号に従う。
共有の \(m\) は差から厳密に消えるため、一般の分散も

\[
\operatorname{Var}(\Delta)=\frac{
\operatorname{Var}(b_1)+\operatorname{Var}(b_2)
-2\operatorname{Cov}(b_1,b_2)}{s^2}
\]

となる。\(\operatorname{Var}(m)\) や \(\operatorname{Cov}(m,b_c)\) を別途加える必要はない。
ただし、これは校正誤差がすべて相殺されるという意味ではない。校正値を同じデータから
推定すると、セル推定量の分散・共分散にもその不確実性が入る。

現在のセルSEは、能力・facet・step・slopeを固定した1変数の情報量から得ている。
固定したパラメータの下で観測が独立し、二つのセルが重ならないという近似に限れば
セル間共分散を0として、条件付き局所SEを \(SE(b_c)/|s|\)、差のSEを
\(\sqrt{SE(b_1)^2+SE(b_2)^2}/|s|\) と計算できる。MMLで能力にEAPを代入する現行セル計算も、
能力を積分した共同交互作用推定にはならない。非単位重みや残差依存を含む一般の
標本分散として、この条件付きSEを解釈してはいけない。

閉形式の例では、\(m=0.8\)、\(SE(m)=2\)、\(s=-1\)、
\(b_1=0.4,b_2=-0.2\)、セルSEが0.3・0.4なら、局所値は0.4・1.0、
差は−0.6、条件付き差SEは0.5となる。旧コードは差を+0.6とし、共有主効果の分散を
二重加算してSEを \(\sqrt{8.25}\simeq2.8723\) としていた。
差は局所値を浮動小数点で引き算する前に共有項を消去し、非常に大きい共通原点や
主効果の欠測によって、計算可能なバイアス差まで変わらないようにした。

### step・傾き・真値分位の回復評価 — 2026-10-04 続行

### BIAS-003・セルの条件付き尤度契約 — 2026-10-04 続行

**対象とした誤り。** 他のパラメータを固定した1変数の尤度を「プロファイル尤度」と呼ぶ説明、
情報量に傾きの二乗が入ることだけをχ²参照の根拠とする説明、RSM/PCMを別のt参照にする説明、
およびLRと異なる旧t確率を多重比較へ渡す経路を修正した。これは nuisance parameter を再推定する
プロファイルではない。現在の `Profile CI *` 生列名と `_profile_bias_ci` 名は互換性のため残すが、
対象は**校正固定の条件付きLRカットオフ区間**であり、公開推論の資格を持たない。

各観測の正の傾きを \(a_i\)、重みを \(w_i\)、セル内の加法シフトを \(b\) とすれば、
負の対数尤度の導関数は
\(g(b)=\sum_i w_i a_i\{E_b(X_i)-X_i\}\)、
二階導関数は \(I(b)=\sum_i w_i a_i^2\operatorname{Var}_b(X_i)\) となる。
RSM/PCMは \(a_i=1\) の場合である。有限の閾値と正の傾き・正の支持重みの下で単調なスコアを
Brent法で解き、返却点の残差・情報量・帰無点との尤度差を確認する。分散は中心モーメントとして
計算し、小さい分散をNaNにして `nansum` で捨てる処理を削除した。

全て最低点/最高点のセルは `no_finite_mle`、探索範囲内に根がないセルは
`search_range_limited` とし、有限MLEや通常のSE/参照確率を返さない。範囲内候補は別列に残す。
計算失敗では理由を保持し、シフト0での計算にすり替えない。極端水準を除外する設定でも該当セルを
消さず `excluded_extreme_level` として保持する。正重み観測数、Person数、重み和・二乗和も記録する。
計算記録は予定・試行・有限解・失敗・除外を分ける。`max_iter` / `tol` は互換引数で、外側反復はない。

**今後の反復研究へ渡す開発候補の方針。** 単位重みの内点セルのみ
`unit_weight_conditional_lr_v1` のχ²(1)参照確率を計算し、`Prob.` と `LR Prob.` を一致させる。
任意重みの曲率とLR差は技術値として残すが、同じχ²分布やカットオフ区間は付けない。

**非線形な識別力の微分。** 同定された線形座標を \(\alpha\)、自由log-slopeを
\(\lambda\)、展開行を \(T_i\)、カテゴリ設計行を \(D_{ik}\) とする。
カテゴリlogitは
\[
l_{ik}=a_i u_{ik},\qquad a_i=\exp(T_i\lambda),\qquad
u_{ik}=D_{ik}\alpha+\theta k.
\]
\(\theta\) を固定した微分は
\(\partial_\alpha l=a_iD\)、\(\partial_\lambda l=lT_i\)、
\(\partial^2_{\alpha\lambda}l=a_iD T_i\)、
\(\partial^2_{\lambda\lambda}l=lT_iT_i^\top\) となる。
したがって条件付き負対数尤度の情報には
\(\operatorname{Cov}_X(\partial l)+E_X(\partial^2l)-\partial^2l_y\) の全項が必要であり、
カテゴリ微分の共分散だけでは足りない。最後のlog-slopeが自由座標の負の和であるため、
異なる自由log-slope同士の交差二階微分も消えない。

独立連続参照 `validation/mml_gpcm_integral.py` は、既存の独立PCM設計行の構成だけを再利用し、
アプリの確率・パラメータ展開・導関数・求積を呼ばない。アプリの移動GH点とは異なり、
完全データの正規密度を \(\theta\) 固定で微分する。
\(s=\log\sigma, z=\theta/\sigma\) に対し、完全データの負対数尤度の
\(s\) スコアは \(1-z^2\)、\(ss\) 微分は \(2z^2\)、構造座標との完全データ交差項は0である。
周辺情報は事後分布で
\[
I=E(H_{\rm complete})-\operatorname{Cov}(g_{\rm complete})
\]

Person真値の分位群は、宣言した正規母集団の25/50/75%点で固定する。
反復rの分位群内の誤差合計をS_r、対象数をN_rとしたとき、母集団のPersonを単位とした
平均誤差は `sum(S_r) / sum(N_r)` で推定する。

RMSEはMSEからデルタ法でMCSEを求め、情報のある反復が一つしかない場合に精度を0と報告しない。

各予定反復の枠を残し、推定不能・区間なしは既知真値の人数を持つNaNとして扱う。
区間が返った場合の被覆率と、失敗も含む既知真値全体に対する被覆率、推定値・区間の
利用可能率を別々に計算する。真値自体が生成できなかった反復は未知と明示し、
全予定対象について被覆率を確定できたかのフラグをFalseにする。

全モデルの座標・Jacobian・共分散変換等の16テストが通過した。

### JMLEの付随パラメータ問題を二項Raschで可視化 — 2026-10-04 続行

元のG4にある「JMLE付随パラメータ可視化」を、2項目の解析的な対照で具体化した。
ZoteroでAndersen (1972) `HYGDM2L9` とAndersen (1973) `P5USGGMB` の書誌を確認した。
1972年論文の[刊行元要旨](https://academic.oup.com/jrsssb/article/34/1/42/7027082)はCML方程式の背景に用い、
ライブラリの添付本文は取得していない。Skrondal & Rabe-Hesketh (2022) の
[公開本文§6](https://link.springer.com/article/10.1007/s11336-021-09816-8)には、1人2観測の場合の
JMLEの確率極限が真値の2倍になる結果が示されている。この2022年論文は今回のZotero検索では
見つからず、公開HTMLを読んだ。以下の尤度・SE・有限分布は個別に直接導出し、独立Rで確認した。

`P(Y_ij=1 | θ_i)=logistic(θ_i-b_j)`、`b=(-δ/2,+δ/2)` とする。
各人の総得点が1の応答は10または01であり、両確率の比は任意のθで `exp(δ)`。
総得点1の人数Mに条件づけると、10の人数Kは `Binomial(M, logistic(δ))` に従う。
Mは全受験者数ではなく、2項目のうち一方だけが1だった人数である。

非極端な両パターンのPerson MLEは、項目平均を0とした座標でθ=0となる。
`n10=K`、`n01=M-K` の両方が正なら、Personを最大化して消去した共同尤度と、
総得点へ条件づけた尤度からそれぞれ次を得る。

```text
δ_hat_JMLE = 2 log(n10 / n01)
δ_hat_CML  =   log(n10 / n01)
SE_JMLE   = sqrt(2 (1/n10 + 1/n01))   [共同尤度のprofile曲率]
SE_CML    = sqrt(   1/n10 + 1/n01)   [総得点条件付き尤度の曲率]
```

ここでいうCMLは、総得点で条件づけてPersonを消去する方法である。
G3の「校正値・Personを固定した条件付きscreen」と同じ操作ではない。
全0/全1のPersonは無制約共同尤度で能力が無限となり、その尤度上限はδによらない。
この対照では総得点1の人数に条件づけ、さらにK=0/Mでは有限の項目MLEがないことを分けて保持する。

Mを増やしても1人あたり2項目のままなので、JMLEは2δへ収束する。
ρ=`logistic(δ)` とすると、JMLEの標本分散は漸近的に `4/[Mρ(1−ρ)]`、
モデル曲率からの分散は `2/[Mρ(1−ρ)]` となり、SE/標本SDの比は `1/sqrt(2)`。
δ=0でも、通常の95% Wald区間の漸近被覆は `2Φ(1.95996/sqrt(2))−1 ≈ 83.42%`。
Hessianが正定値で停留点に十分近いことだけでは、付随パラメータが増える状況でのSEや
区間被覆を証明できない。最適化の高速化・精度と推定法の数学的性質を分ける対照である。

`jmle_two_item_oracle.py` は、M=8〜16,384の10値、δ=−0.5/0/0.5/1の40条件について、
K=0〜Mを全て列挙した。乱数標本やMonte Carlo反復ではなく、既知の二項確率による計算である。
浮動小数点で全確率和を確認し、非常に小さい有限MLE不存在確率には対数値も保存する。
推定可能条件付きのbias・RMSE・標本SD・RMS SE・被覆と、全カウントでの区間提供/被覆を分ける。

| M=16,384の対照 | CML | JMLE |
|---|---:|---:|
| 真の差δ=0.5での平均推定差 | 0.500032 | 1.000064 |
| 同条件でのRMSモデルSE / 標本SD | 0.999966 | 0.707082 |
| 同条件での95% Wald区間被覆 | 94.978% | 約3.34e−47 |
| 真の差δ=0での95% Wald区間被覆 | 95.012% | 83.328% |

独立Rは閉形式を使わず、2パターンの能力と項目差の3座標で行尤度を最小化し、

最大差は点8.89e−16、NLL8.89e−16、SE2.09e−8、最大絶対勾配2.23e−15。
最初のBFGSのみでは1条件の勾配3.13e−6が既定1e−6を超えたため、その失敗を保持した。

### 校正を固定したSEと、校正を推定した残差の標本変動 — 2026-10-06 続行

正式計算の結果とは独立に、校正値の扱いによる不確実性の違いを解析的に確認した。
ZoteroのSkrondal & Rabe-Hesketh (2009)、キー `E2JA7NDA` の書誌を再確認した。
[刊行元要旨](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/j.1467-985X.2009.00587.x)は、
事後SD、周辺予測誤差のSD、周辺標本分布のSDを区別している。ライブラリの添付本文は読んでいない。
また、Sibley et al.の[公開論文§1.1](https://pmc.ncbi.nlm.nih.gov/articles/PMC6092959/)では、
効率的スコアにnuisance scoreの射影項が入る。この論文は今回のZotero検索では見つからず、
公開情報を参照した。以下の正規モデルの式・結果は、その論文のMFRMへの適用結果ではなく、
行ごとの線形係数から別途導出した対照である。

独立な既知分散1の正規モデル `Y_i = λ + b x_i + ε_i` を考える。
`x=1` の人数をn1、`x=0` をn0、N=n1+n0とする。校正λを固定してから群1のシフトを
求める1変数の尤度は、いずれの校正方法でも曲率n1を持つ。しかし返却値の標本分散は異なる。

| 校正・推定経路 | 返却するシフト | 期待値 | 標本分散 |
|---|---|---|---|
| 真のλが既知 | 群1平均−λ | b | 1/n1 |
| 同じ全データでb=0としてλを校正し、その値を固定 | 群1平均−全体平均 | (n0/N)b | 1/n1−1/N |
| 独立なM人の校正平均を固定 | 群1平均−校正平均 | b | 1/n1+1/M |
| λとbを同時に推定し、λをプロファイル | 群1平均−群0平均 | b | 1/n1+1/n0 |

最後の経路のプロファイル情報は `n1*n0/N` であり、他の3経路の固定λでの曲率n1とは違う。
同一データの全体平均を固定した残差は、非ゼロ効果の下ではbそのものも推定していない。
独立校正の場合には、校正平均の誤差が加わる。したがって「校正を推定したのでSEに常に
同じ補正を加える」という扱いも適切ではない。

b=0で、固定校正のLR差 `n1 * returned_shift²` は、標準χ²(1)をそれぞれ
`1`、`n0/N`、`1+n1/M` 倍した分布を持つ。共同プロファイルLRは標準χ²(1)となる。
これらはこの既知分散正規モデルでの有限標本の等式である。
n1=n0=M=8では、通常のχ²(1)の5%点を一律に使うと次の率になる。

| 経路 | 全標本での帰無棄却確率 |
|---|---:|
| 真のλが既知 | 5.0000% |
| 同じデータの帰無校正を固定 | 約0.5575% |
| 独立な推定校正を固定 | 約16.5776% |
| 共同プロファイル | 5.0000% |

`validation/bias_gaussian_calibration_oracle.py` は4組の人数配分・4経路について、
閉形式の期待値・分散と各独立行の線形係数を有理数演算で照合する。
正規尾確率だけを浮動小数点で評価し、応答の乱数生成・fit・Monte Carlo反復は行わない。
全16経路の照合が通過した。再現物は `g4_bias_gaussian_calibration_20261006` に保存する。

この対照には潜在Person、EAP、離散応答、境界、重みがない。そのため、この棄却率や補正倍率を
本アプリの数値として報告せず、G3の144,000反復や登録済み固定対照へ加算しない。
G3の4経路を分け、推定校正後の残差区間に生成効果bの被覆率を付けない数学的理由を補強する。
MMLのEAP事後SDも、校正値を推定した後の標本SEと同一視しない。正式計画・判定基準は変更しない。

### 数学的対象を保ったgrouped MMLの勾配評価の効率改善 — 2026-10-06 続行

利用者から、統計的検証を最優先としつつ、確定した数値計算の効率も再検討する指示を受けた。
今回の対象は同じ有限求積の尤度・導関数である。求積点数・重み・最適化手順・停止条件・
受入幅を変えず、勾配を計算する有限和の順序だけを変えた。現在の正式研究は隔離した
凍結版で継続し、改善した作業版へ途中で切り替えていない。

Person n、求積点 q、共通応答パターン i、カテゴリー kについて、度数をc_nik、
Personごとの事後求積重みをπ_nq、カテゴリー確率をp_qik、logitをl_qikとする。
後者のlogitはPersonの識別子には依存しない。このときNLLの勾配は

```text
C_qik = Σ_n π_nq c_nik
T_qi  = Σ_k C_qik
gradient = Σ_qik (T_qi p_qik − C_qik) ∂l_qik/∂parameter
```

### G2：BICの標本単位とAICcの適用根拠 — 2026-10-06

正式MML計画はPerson数、アプリは応答行数（重みがあれば総和）をBICの罰則に使っていた。
Personごとの応答ベクトルを独立単位とする現在のMML研究では、次の範囲を明示する。
共通パラメータの次元dを固定し、各Personの応答数を有界とし、正則で同定された内点で
Person数Pに対して観測情報H_P/Pが正定値Iへ収束するなら、

```text
log det(H_P) = d log(P) + log det(I) + o_p(1)
BIC = −2 log L_marginal + d log(P)
```

となる。これはこの漸近範囲での導出である。全応答数がPの定数倍なら、両罰則の差は
O(1)だが有限標本の数値は異なるため、比較では定義を揃える。
課題・評定者・パラメータ数やPerson内反復も増える場合、非単位重み、境界解、
情報の退化にそのまま一般化しない。Delattre・Lavielle・Poursat (2014)の
[混合効果モデルのBIC論文](https://doi.org/10.1214/14-EJS890)も、
標本数を一律に選べず情報の成長率を区別する必要を示す。
同論文のPerson内反復も増やす導出を、今回の有界反復の証明として流用していない。

作業版では新規MML fit・候補比較・単独の尤度表・保存済み結果の表示をPerson数へ統一し、
`BICSampleSize`、`BICSampleSizeBasis`、適用範囲を明示した。
`N` と `LogLikPerObs` は応答量の記述として残す。旧結果はコピー上で再表示し、
旧BICを `SavedBIC` に保持する。Person数の記録が欠ける・不正な場合は、応答数を代用せず
BICを利用不能にする。JMLEの応答数による従来値は技術用に限定し、増加するPerson
パラメータを含む通常BICの資格が得られたとはしない。

以前のAICcは `AIC + 2K(K+1)/(N−K−1)` を機械的に計算し、N/K<40で推奨していた。
[Hurvich・Tsai (1989)の原論文要旨](https://doi.org/10.1093/biomet/76.2.297)で確認できる
導出対象は回帰・自己回帰時系列であり、このMFRM周辺尤度・JMLEへの補正を導出した
根拠ではない。人数比だけでは適用を証明できないため、現在の比較ではAICc・差・重み・
比を利用不能とし、`AICcStatus=unavailable_no_mfrm_small_sample_derivation`、
`AICcRecommended=False` にした。過去に保存した比較表自体は改変していない。
古い尤度表のキャッシュが残っていても、現在の画面・結果bundle・CSV・APA用表は
要約のコピーから表を再構成する。モデル比較のキャッシュキーも定義更新を識別し、
母集団SD・自由SD設定を含める。古い比較を新しい定義の結果として再表示しない。

Zoteroの `Y9PP98UY`（[Aho・Derryberry・Peterson, 2014](https://doi.org/10.1890/13-1452.1)）については、
添付 `MLTD6LSG` の索引済み6ページを取得し、AICとBICの目的を対比する箇所を読んだ。
予測損失と候補モデルの同定を区別する記述を、将来の推奨基準を設計する際の論点とする。
同論文がMFRMのAICcを導出したとは扱わない。Hurvich著者名のライブラリ検索は0件で、
その論文は外部一次資料の要旨を確認した。Delattre論文は一次論文の検索索引本文の該当節を
照合したが、今回のツールではPDF全体を取得できなかった。読取範囲を混同しない。

### アプリ共通求積の高次数対応とゼロ重みの扱い — 2026-10-06続行

正式なgrouped計算とアプリの出力経路を接続するため、両者の求積則を点検した。
アプリ側の `gauss_hermite_normal` はNumPyの `hermgauss` を毎回呼び出していた。
NumPy 2.4.4 / SciPy 1.17.1の実機で旧処理を再現すると、Q641で487個、Q1281で

統計モデルが不適格になるという意味ではない。

[NumPy 2.4の公式文書](https://numpy.org/doc/2.4/reference/generated/numpy.polynomial.hermite.hermgauss.html)
も、100次を超える計算の問題を注意事項として記している。
[SciPy 1.17の公式文書](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.special.roots_hermitenorm.html)
では、`roots_hermitenorm` が `exp(-x²/2)` に対する求積を行い、150次を超える範囲に
安定な漸近アルゴリズムを使うことを確認した。今回は依存ライブラリを更新せず、既存の
SciPy 1.17.1の関数を使った。文書の版と実機のパッチ版は区別して保存している。

  過去の呼出しの節点・重みを書き換えても、後続の推定には影響しない。

#### 基本式・同定と推定対象

現在の共通所有facetのGPCMは、概略として次の隣接カテゴリー式を使う。

```text
log(P_k / P_(k-1)) = a_c (theta - rater - task - criterion - step_ck)
a_c = exp(lambda_c),  sum_c lambda_c = 0
theta ~ N(0, sigma²)
```

識別力は、能力だけでなくfacet・stepを含む予測子全体に掛かる。
Pythonとmfrmrのこの式は一致する。位置・step・sigmaを同じ正の係数で拡大し、
識別力を逆数倍すると確率が変わらない尺度の自由度を、識別力の幾何平均1で固定する。
Rater/Taskの和0、Criterionの位置、各stepの和0と母集団平均0の対応も必要である。
同定制約を置くことと、特定データに有限で一意な最大値があることは別の問いである。

今回の確認結果は次のとおり。

| 論点 | Pythonの正式計算 | mfrmr開発版との照合・判定 |
| --- | --- | --- |
| GPCMの確率式 | 完全な隣接予測子へ正の識別力を掛ける | カーネルの数値一致を確認 |
| 尺度 | 識別力の幾何平均1、母集団SD自由 | 一つの識別力facetの対応する設定で整合的 |
| 識別力の範囲 | 全展開log-slopeを−3〜3に制限。従属する最後の座標も制限 | mfrmrは追加の有限の箱を設けない。正値・幾何平均1とは異なる制約 |
| 母集団SD | 0.05〜10の探索範囲 | これも同定条件とは別の範囲制約として説明が必要 |
| 推定器 | 固定GH641/1281、直接SLSQP、cold startと必須polish | 直接MMLは妥当な方法。GPCMでEMが必須という意味ではない |
| 返却点 | 有限求積の停留性・内点・情報行列・求積次数差を検査 | 大域的最大値・連続積分の精度・標本性能の保証とは区別する |
| 共分散 | log-slope・log-sigmaを含む全共同観測情報を反転し変換 | 適切な構成。識別力だけのHessianブロックの反転へ簡略化しない |

#### 有限和と微分の対応

mfrmrの保存済み `R/core-adaptive-quadrature.R` を参照し、Pythonでは標準正規座標で導出した。
mfrmrの物理的theta座標の導出やlog分散座標と、Pythonのlog標準偏差座標を区別する。
較正母数をpsi、Personごとの対数尤度をellとすると、以下を使う。

```text
h(z, psi) = ell(sigma*z, psi) - z²/2
H = -h_zz(m, psi) = 1 + sigma² Σ cell_count * a² * Var(K) > 0
h_z(m, psi) = 0,  s = H^(-1/2),  z_q = m + s*x_q

I_Q = Σ w_q * exp(ell(sigma*z_q) - z_q²/2 + x_q²/2) * s
m_psi = h_z,psi / H
(log s)_psi = -(H_psi + H_z*m_psi)/(2H)
d log(I_Q)/d psi = E_Q[h_psi + h_z*(m_psi + s*x*(log s)_psi) + (log s)_psi]
```

最後の期待値は適応求積後の正規化した事後重みによる。
元の事前分布を変えず、移動した事前重みを再正規化しない。
モードは厳密に凹な1変数問題なので、カテゴリー得点の範囲から得た括弧内で
Newton法と二分法を併用し、最終scoreも確認する。

#### 情報の弱い方向を含む精度判定

情報行列の最大要素差が小さくても、小さい固有値に対応する方向のSEは不安定になり得る。
独立連続積分の情報を `H_ref = L Lᵀ` とし、有限適応和の情報との差について

```text
rho = || L^(-1) (H_adaptive − H_ref) L^(-T) ||_2
```

を追加した。両情報の正定値性・対称性・条件数を確認してから計算する。
`rho < 1` なら、同じ母数位置・同じ共同座標の任意の固定された線形contrastについて

```text
1 / sqrt(1 + rho) <= SE_adaptive / SE_ref <= 1 / sqrt(1 − rho)
```

となる。これは情報の行列不等式と逆行列の順序から得られる数値的な摂動の関係である。
参照情報自体が真の連続積分と一致する証明や、標本分布・区間被覆率の保証ではない。
相対基準は `rho < 0.005` とした。この基準は約0.25%以内のSE比に対応する。
絶対要素差 `1e-3` も併用し、どちらか一方だけで採用しない。

差分情報は有限和の正しい解析勾配から、幅 `1e-4` と `5e-5` で求め、Richardson外挿する。
幅による変化・非対称性も判定する。新しい解析的Hessianを実装したわけではない。
連続対照は、既存の密度微分・非線形log-slope項を含む独立積分を再利用する。
誤差の推定許容量も最小固有値に対して評価し、弱情報方向で拡大する誤差を見落とさない。
数値積分誤差と裾誤差を合成する際には、score外積の交差項も上から見積もる。
この数値誤差は `quad_vec` の推定値を含み、厳密な区間包絡とは呼ばない。
Newton補正とその勾配誤差寄与の検査も、真の解への距離の厳密な保証とは区別する。

返す事後確率配列は元の列数・順序へ戻し、省いた列を0とする。
