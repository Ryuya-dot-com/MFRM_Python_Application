## 固定SDの水準・指定した差の近似区間を提供する経路 — 2026-10-28、未公開

下記の優先順の再評価を受け、数値点検から対象別の区間提供へ接続した。
`mfrm_app/structural_intervals.py` は、単位重み・単純な中心化の固定SD RSM／PCMについて、
選択したファセットの水準と事前指定のA−Bを、全構造観測情報に基づく点ごとの漸近正規区間として返す。
通常設定の `noncenter_facet="Person"` を指定どおり扱い、1,000評定の一律上限を廃止した。
64自由座標と集約配列の資源上限は維持する。アンカー・群制約・ダミー・潜在回帰・正則化・非単位重みは対象外。
推定値・母集団SD・中心化を変更する操作や、自動の再最適化は含めない。

### 判定の根拠と適用範囲

[報告要件の数値受入v1](mfrm_reporting_requirements.md#se-reference-contract-20261028)を今回の計算前に固定した。
mfrmr候補の `R/core-native-location-inference.R` を参照し、Python側では分析時q点と同一点の2q−1点の
両方で、SE尺度の停止誤差 `sqrt(gᵀ V g) ≤ 0.01` と情報行列の逆行列残差を確認する。
さらに求積間の勾配変化と全共分散の相対変化を判定する。共分散の基準0.01は全方向の分散の1％に対応し、
個別SEが同じでも差のSEが異なる反例を見落とさない。非正定値を固有値補正して通過させない。
最適化の明示的な正常終了、設計の全階数、構造的分離の証明がないこと、入力・返却点・NLLの整合も必要である。

この判定は局所的な数値受入と求積感度の点検であり、連続積分への厳密な誤差上界ではない。
正しい応答・母集団モデル、Person間の独立性、割当・欠測の無視可能性、識別された内点、
固定次元で情報量が増大する漸近近似を仮定する。条件を満たした行だけ `CIEligible=True` とし、
**有限標本被覆率は全行 `CoverageQualified=False` のまま**とする。
Person得点、自由SD、同等性・多重比較、モデル選択、信頼性等へこの資格を転用しない。
従来の一般表は保留を維持し、新しい「Specified Structural Intervals」表に対象別の区間を掲載する。

## 固定SD RSM／PCMのSE点検を通常画面へ接続 — 2026-10-28、未公開

先に整理したSE仕様を、共有モジュール `mfrm_app/mml_fixed_sd_review.py` と通常結果画面へ実装した。
従来の画面内比較は、限定したPCMの尤度・EAP・事後SDまでだった。新しい比較では固定SDのRSM／PCMに対し、
ファセット水準と中心化した段階効果のSE、停止誤差のSE尺度、求積を変えた同一点でのSE差も保存する。
推定器・元の結果・出力資格は変えず、明示的なボタン操作で実行する。旧PCM専用の開発CLIの範囲は拡張していない。

全構造座標の観測情報を、既存の集約尤度のLouis式で計算する。通常の行単位尤度と勾配も毎回照合する。
母集団SDは固定量なので、その座標を除いた全構造情報を逆行列にしてから `J V Jᵀ` を計算する。
最後の従属水準・段階も含め、ファセット間や段階との共分散を落とさない。
個人の事後SD、SDを推定したときの不確実性、FACETSの条件付きModel SEとは別の対象である。

停止誤差の表示は `max |J H⁻¹g| / SE`、JSONには `sqrt(gᵀ H⁻¹g)` も残す。
局所近似であり、実際の再推定移動量・大域的な最大値・被覆率の合格判定とはしない。
情報行列の固有値補正はせず、非正定値・設計の階数不足ではSEを空欄にする。
構造的な分離方向を証明できた場合も表示し、その証明がないことを有限解の存在保証にはしない。
入力・返却座標・構造パラメータ・当初NLLの整合を確かめ、計算ソースと依存環境もキャッシュ識別に含めた。

### 上記の方針は最適か：目的に対する再評価

ユーザーの問いを受け、現行の目的、Pythonの実装、Developer側mfrmrの同じcommit、
FACETS／ConQuestの公式説明を再確認した。**全構造情報に基づくSEという方向は維持するが、
点検機能の追加を主な進捗とする順序は改善が必要である。** 120項目の成功は当該実装の根拠であり、
推論提供に必要な作業が完了した証拠ではない。

具体的に次の不足を確認した。

- `output_qualification.mml_inference_hold_reason()` は方法名と固定／推定SDだけから全MMLを保留する。
  新しい点検記録は参照しないため、点検を繰り返しても現在の利用資格は変わらない。
- 画面・共通推定関数の既定値は `noncenter_facet="Person"` だが、新しい点検が使う集約尤度は
  構造ファセットの一つが非中心化されていることを要求する。既定設定を含む全RSM／PCMへ対応したわけではない。
  また、点検の1,000評定上限は、既存の中規模作文研究の200／500人×6評定＝1,200／3,000評定を除外する。
  これは同期実行の資源制限であり、統計的にSEを計算できない証拠ではない。
- 個別水準・中心化段階のSEの相対変化だけでは、指定した差のSEの安定性を判定できない。
  全共分散はJSONに保存しているが、現在の最大値表示にその比較は含まれない。
  停止誤差・求積誤差を、実際に提供する対象の変換へ対応させる必要がある。

最後の点は代数的な反例でも確認した。3自由座標の共分散を
`V1=[[1,.4,-.4],[.4,1,0],[-.4,0,1]]`、
`V2=[[1,-.4,.4],[-.4,1,0],[.4,0,1]]` とする。
両方とも最小固有値は約0.4343で正定値。第4水準を前三水準の負の和にすると、
全4水準のSEはどちらも `[1,1,1,sqrt(3)]` で同一だが、第一・第二水準の差のSEは
約1.0954から1.6733へ52.75％変わる。これは作った共分散による数学的反例であり、
今回のMFRMデータで52.75％の誤差が観察されたという意味ではない。
既存4点のJSONを用いた再計算でも、GH15→121の最大SE変化は、個別対象だけなら
bridge4で0.761％、crossedで0.120％だが、全ての線形結合の最大値は各0.974％・0.227％だった。
この最大方向を事後的な有意性検定へ転用せず、報告する差を事前に定義する。
新しい推定・シミュレーション・連続積分は実行していない。

改善する順序は、(1) 提供する水準・事前指定の差と条件付きの意味を確定し、
(2) 既存の通常設定・作文例の保存結果で、停止・全情報・対象の求積感度・境界の必要な証拠を照合し、
(3) 必要な箇所だけ数値計算を改善して、(4) 同じ対象別資格を表・図・保存・再読込へ適用する、である。
失敗・対応外には理由を返す。手動で複数の技術指標を読むことを、初心者の必須操作にはしない。
mfrmrの `CIEligible` と `CoverageQualified` の区別を参照するが、Rの資格や閾値を無条件には移植しない。
点検機能と既存の成功証拠は保持し、この再評価だけで推論保留や正式研究の停止を解除しない。

### SEの対象と計算法の対応

| 参照する計算 | 確認した意味 | Pythonへ取り入れる点 |
|---|---|---|
| FACETS Model SE | モデルの応答情報に基づく精度。個人について情報の逆平方根を説明している | 通常JMLEの条件付き情報SEと対応させ、全共同共分散を含むSEとは呼ばない |
| FACETS Real SE | `Model SE × sqrt(max(Infit, 1))` | 適合度による拡大として明示。偏りの補正、サンドイッチ共分散、校正誤差の伝播とは別 |
| ConQuest quick / empirical | quickはパラメータ間依存を省く近似。empiricalは尤度の数値微分を使う完全情報に基づく漸近SE。JMLではempiricalを使えない | 比較時に`stderr`を記録。empiricalはブートストラップではない。quickとの一致を共同SEの証明にしない |
| ConQuest EAP | 校正されたモデルに条件づけた事後分散。構造母数のSEとは別 | 個人の事後SDとEAP推定量の反復標本SEを区別。推定用nodesと事後得点用の計算条件も分ける |
| mfrmrの通常JML | 他母数を固定した観測情報SEを診断に保持し、通常の構造推論と区別 | 条件付きSEを残す。共同推定誤差や付随パラメータの偏りを解決したものに昇格させない |
| mfrmrのMML区間 | 全共同観測情報を反転してから対象へ変換。対応する区間APIでは数値的利用可否と被覆率の資格を区別 | 出力対象別の判定、共同共分散、失敗理由と保存・再表示の一貫性を参考にする |

公式根拠はFACETSの[SE指定](https://www.winsteps.com/facetman64/standarderror.htm)、
[Table 7](https://www.winsteps.com/facetman64/table7.htm)、[情報関数](https://www.winsteps.com/facetman64/graph_window.htm)、

mfrmrの参照実装は `R/api-estimation.R`、`R/api-facet-intervals.R`、`R/mfrm_core.R`。
Rでの推定母集団分散の座標はlog(σ²)、Pythonの共同経路はlog(σ)なので、共分散の対応には座標変換も必要となる。

### 0で判断が変わらなくても、任意の境界で同じとは限らない

既存のGH31／81の保存値を再推定せずに読み、主・副対比について、点推定が閾値を超えるか、

例えば、端点が`a < b`なら、厳密な「端点 > 閾値」の判断が違う範囲は`[a,b)`、
「端点 < 閾値」なら`(a,b]`となる。この幅は最大`1.074e-4` logits、SE換算の最大値は

### 実務で次に変えるものを選ぶ

| 選択 | 今回の結果から点検すべきこと |
|---|---|
| 評定配置を見直す | 人数・評定数に加えて能力群・課題の担当構成と群間の共通答案を確認する。担当の偏りを残したまま評定数だけ増やしても偏りが解消するとは限らない。今回の10%接続を最低基準として転用しない |

### 速さと数学的意味を揃える

群化は個人×共変量セル×カテゴリーの度数で同じ尤度を表す。多項係数を追加せず、同一人物の
評定は積を取ってから能力分布で積分する。情報行列ではLouisの欠測情報項と交差項を保つ。
単に各評定を独立として情報を足す高速化とは異なる。固定SDの共分散は、SD座標を除いた構造情報行列を
**先に切り出してから逆行列化**する。SDも推定する場合の逆行列部分行列とは意味が異なる。

最適化器の停止成功に加え、勾配最大絶対値1e-4、Newton補正1e-5、必須第2段階の移動1e-5、
制約・正定値・条件数・対称性・目的関数の非悪化を点検する。これらはこの座標・範囲の数値基準であり、
普遍的な収束証明ではない。速さは基準を満たした同じ精度の対でのみ評価する。
時間切れ・例外・未実施も保存し、結果を見て閾値や反復数、求積点を変更しない。

SEの近さは区間の被覆率の保証ではない。被覆率を計算できても有限GH推定量についての探索的な評価とし、
8点の連続積分照合を全反復の精度認定に拡張しない。固定N(0,1)が正しい場合だけを生成しているため、
能力分布が配置ブロックごとに異なる場合、局所依存、評価者の経時変化、自由SD、PCM/GPCMやアンカーには一般化しない。
現在のアプリの推論保留は、この研究だけでは解除しない。

### 2. 分散0で「区間幅0」が生じる境界

現行の縮約は、元の推定値を x、SEを s とすると、ゼロを中心に

```
tau2_hat = max(0, mean(x^2) - mean(s^2))
shrunk   = tau2_hat / (tau2_hat + s^2) * x
ShrunkSE = sqrt(tau2_hat * s^2 / (tau2_hat + s^2))
```

と計算する。3要素の `x = [-0.1, 0, 0.1]`、各 `s = 0.2` では、
`mean(x²)=0.0066667 < mean(s²)=0.04` のため、推定分散は0となる。
縮約後の点も `ShrunkSE` もすべて0になることを、修正前の関数から再現した。
この例で図の「95% CI」が幅0だったのは、**推定した分散を既知として代入したため**である。
データが3要素の完全な同等性を証明したわけではない。

正規階層モデルで分散が既知なら、上式は対応する条件付き事後分布の式として解釈できる。
しかし、データから推定した分散を代入する場合、その推定の不確実性は含まれない。
さらに、この後処理はMFRMの制約・校正パラメータ間の共分散を統合した階層推定ではない。
原点を変えても同じ縮約になるわけではなく、ゼロへ縮めるという仮定も明示する必要がある。
完全なベイズモデルへ置き換える場合にも、事前分布・推定対象・数値計算の別途検証が必要であり、
事後区間へ名前を変えるだけでは解決しない。

現在は数式・点推定を保持し、`ShrinkageCI_Status=unqualified_plugin_uncertainty` と
`stat.eb_shrinkage.uncertainty_unqualified` を新規・保存済みの表へ付す。

### 2. 「差がない」と「同等」の間に、判断できない状態がある

説明用の正規参照計算で、有意水準5%、同等性幅±0.2を固定した。
この幅は研究上推奨する値ではなく、4つの状態を区別する計算対照である。

| 差の推定値 | SE | 0との差の検定 | 同等性のTOST | 読み方 |
|---|---:|---|---|---|
| 0.00 | 0.05 | 非有意 | 成立 | 指定した幅の内側に収まる精度がある |
| 0.30 | 0.10 | 有意 | 不成立 | 0との差は捉えるが、この幅での同等性は示さない |
| 0.10 | 0.02 | 有意 | 成立 | 0ではない小さな差を精密に捉えている。両方の成立は矛盾しない |
| 0.00 | 0.20 | 非有意 | 不成立 | 精度が不足し、差の存在も同等性も示せない |

通常の2つの片側検定によるTOSTを各5%で行う場合、対応する**両側90%信頼区間**が同等性幅の内側に
厳密に入る条件と一致する。0との差を調べる両側5%検定には95%区間が対応する。
この90%は、以前のPerson表のQ05〜Q95という条件付き事後区間とは、対象も根拠も異なる。
[Lakens (2017)](https://journals.sagepub.com/doi/10.1177/1948550617697177)

保存済みPCMのGH121終点のC0−C1は−0.026796、連続積分情報による曲率SEは0.176771だった。
これを仮に正規参照に当てはめると、0との差のp値は0.8795、90%区間は[−0.317558, 0.263967]となる。
±0.2のTOSTは不成立、±0.5では計算上成立する。
同じ±0.5でも共分散を捨てたSEでは区間が[−0.729551, 0.675959]となり、不成立に変わる。

このPCMで正規参照やSEの被覆が妥当とは確認しておらず、上の結果を公表可能な同等性と認定していない。

### 3. 個別95%と、全比較を同時に95%は異なる

各区間が正確に95%を被覆し、推定誤差が独立という説明用の正規モデルでは、
m区間のうち少なくとも1つが真値を外す確率は `1−0.95^m` になる。

| 比較数m | 個別95%区間の少なくとも1つが外れる確率 | Bonferroni区間での同確率（この独立例） |
|---|---:|---:|
| 1 | 5.00% | 5.00% |
| 5 | 22.62% | 4.90% |
| 20 | 64.15% | 4.88% |

Bonferroniは、各区間の非被覆確率をα/m以下にできることを前提に、依存の形によらず全体をα以下に抑える。
今回の表の正確な数値は独立な正規モデルの代数計算であり、相関のあるMFRM出力の実測値ではない。
元のSEや参照分布が妥当でなければ、多重性補正だけで全体95%を保証できない。
[NISTの同時区間の説明](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm)

保存PCMのRater差・Task差・Criterion差を3比較の一群とした技術計算では、
Criterion差の個別95%区間[−0.373261, 0.319669]が、Bonferroni区間では[−0.449982, 0.396390]になった。
Holm補正p値と通常の未補正95%区間を併記する場合も、同じ判定基準だと説明しない。
HolmとBonferroniも別の手順であり、今回の区間をHolm区間とは呼ばない。

現行のバイアス・セル点検はファセット対ごとのfamilyを用い、計算不能セルを分母に残し、
Holmを候補フラグに用いている。BHはそこでの公表可能な結論を与えない。
`[.01, 欠測, .03, .04]` の4比較は、Holmで `[.04, 欠測, .09, .09]` となることを
Rの `stats::p.adjust(..., n=4)` と照合した。
これも補正式の確認であり、入力p値やその依存構造の検証を代替しない。
[R公式p.adjust仕様](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)

### 4. 「全ペア同等」の単一主張と、ペアごとの結論を区別する

全ての指定ペアについて同等性検定が成立した場合だけ「全ペアが同等」とする**単一の全体主張**は、
intersection–unionの論理になる。どれか1つでも非同等なら、その真の帰無仮説を誤って棄却しなければ
全体の同等性は宣言できない。したがって、各検定が水準αを守るなら、全体を誤って宣言する確率もα以下である。
この主張だけのために、比較数によるBonferroni補正が常に必要というわけではない。

一方、「同等と判定できたペアだけを選んで列挙する」「どれかに差がある」「最も良い要素を選ぶ」では
誤りを管理する対象が変わる。全体主張の論理を個別の多数の主張に流用しない。
また、計算不能・未接続のペアを落としてから「全て」と呼べば、最初に指定した対象の全体主張ではなくなる。
今回の旧画面の問題は、単にTOSTに多重補正がないことではなく、共分散・資格・失敗比較・主張の定義まで
揃っていなかったことである。

順位も同様に、点推定値を並べた順位と、順序が確かであるという推論を分ける。
最上位を結果から選んで、その要素だけの未補正区間を示しても、最上位の確かさは分からない。
検証された同時の差の区間等を用いて確認できる比較と未確定な比較を分け、全順位を無理に確定しない。
頻度論的CIから、そのまま「この要素が1位である確率」を読み取らない。

## 原点・制約・符号を変えても、同じ判断になるか — 2026-10-23 続報

**係数表の同じ名前の列を比べる前に、同じ推定対象へ換算する。SEだけの換算では足りず、共分散も必要になる。**

### 1. 表示されたSEの違いが、精度の違いとは限らない

欠測例の保存済みGH121終点と、同一点の連続積分情報を使った結果を示す。

| 評価者効果の表現 | 表示されるR0 | R0のSE | 元の方向のR0−R1 | その差のSE |
|---|---:|---:|---:|---:|
| R0＋R1＝0 | 0.012220 | 0.084221 | 0.024439 | 0.168443 |
| R1＝0 | 0.024439 | 0.168443 | 0.024439 | 0.168443 |
| R0＝0 | 0 | 0 | 0.024439 | 0.168443 |

平均0のR0は2人の差の半分、R1＝0のR0は差そのものであり、同じ名前でも対象が異なる。
固定されたR0のSE＝0も、その評価者の効果を無誤差で知っていることを意味しない。
**同じ差へ換算した推定値とSEは一致した。**

この同値性には、Criterion側の補正が必要だった。元のモデルの予測子を
`theta + r_i − t_j − c_k` とし、`r_0=r, r_1=−r` とすると、R1＝0の表現は
`r'_0=2r, r'_1=0, c'_k=c_k+r` となる。差し引きが相殺して、応答確率が変わらない。

これは丸め誤差ではなく、予測するモデルを変えている。

なお、この例は自由なCriterion位置との間で原点を取り直す、同じ自由度のモデルである。
別の固定アンカー、罰則、事前分布、追加制約がある場合に、任意のアンカー変更が同値だとは仮定しない。

### 2. 共分散を捨てると、差にも平均にも問題が生じる

平均0の元の座標で、同じ連続積分情報行列Iを使い、3つの処理を分けた。

| 対象の曲率SE | 全逆行列 `I^{-1}` | 逆行列を作ってから非対角を捨てる | 情報の対角だけを逆数にする |
|---|---:|---:|---:|
| Criterion C0−C1 | 0.176771 | 0.427244 | 0.228600 |
| Criterion C0・C1の平均 | 0.288889 | 0.213622 | 0.114300 |

前者の省略は、各パラメータの周辺的なSEが分かっていても、それらを独立として組み合わせる処理である。
後者は `diag(1/I_jj)` であり、`diag(I^{-1})` とも異なる。
今回の正の共分散は差では相殺し、平均では加算されるので、無視すると差のSEは大きく、平均のSEは小さくなった。
**共分散を無視する処理を、一律に「保守的」または「楽観的」と呼ばない。**

省略した計算は、同じ対象でも原点の取り方に依存し得る。
例えば、逆行列の非対角を捨てたC0−C1のSEは、平均0の表現で0.427244、R1＝0で0.443243だった。
全共分散を保持した0.176771は不変である。
また、情報の対角だけから求めたR0−R1のSEは、平均0で0.168420、R1＝0で0.161749となった。
この場合、他の座標を固定するという操作自体が表現によって違う方向を固定するため、
単なるソフトの数値誤差として扱うことも適切でない。

### 3. 同じ対象へ戻すための計算

自由座標の可逆な線形変換を `eta=A beta` とすると、

\[
\Sigma_\eta=A\Sigma_\beta A^T,\qquad
I_\eta=A^{-T}I_\beta A^{-1}.
\]

元の対象 `c^T beta` は、新しい座標では `c^T A^{-1} eta` となる。

## SE・CIの対象と校正不確実性 — 2026-10-23 続報

**SE、事後SD、信頼区間（CI）、事後信用区間（CrI）を、同じ精度指標としてまとめない。**
連続CDFの精密化は、校正値を固定した事後分布の計算を改善する。校正値自体の推定誤差や、
同じ真値の下で評定を取り直したときの振る舞いまで確認したことにはならない。
今回は現行コードを読み、既存の不確実性テストを実行したうえで、解析的に点検できる小例を作成した。
新しい被覆率シミュレーションや正式G3の再開ではない。

### 1. 現行アプリのSE・区間が表すもの

| 出力 | 計算対象 | 解釈上の制限 |
|---|---|---|
| MMLのPersonの `SE` | 求積事後分布のSD。`SE_Method` に事後SDと記録 | EAP推定量の標本SEではない。項目・評価者・段階・識別力・母集団の校正値を固定している |
| MMLのPersonの通常区間 | `EAP ± z × conditional posterior SD`。既定の水準は95% | 事後分布の正規近似であり、連続CDFの分位点でも、校正誤差を含む頻度論的CIでもない |
| 別の事後得点表のQ05〜Q95 | 有限求積事後の5%・95%分位点 | 中央**90%**区間。通常表の95%正規近似区間とは水準も方法も違う。日英画面の区間幅表示は90%と明示されている |
| 対応範囲のMML構造パラメータ | 周辺尤度の観測情報を逆行列化し、報告値へデルタ法で変換 | 固定SD・無罰則等の制限、パラメータ数上限、階数・固有値の点検がある。逆行列が得られても標本SEや被覆率の妥当性確認にはならない |
| JMLE等の条件付きSE | 他の推定パラメータを固定した応答情報からの近似 | 同時推定の全不確実性を伝播していない。通常のWald区間はスクリーニング用の近似として扱う |
| 固定アンカーに対する構造変換 | 固定値の微分が0なら、デルタ法の分散も0 | アンカーを今回の最適化で推定していないことの結果。外部研究でのアンカー誤差が0という意味ではない |

`annotate_measure_uncertainty` は以上の方法・状態を記録し、`qualify_measure_uncertainty` が
固定SD・自由SDの双方のMML推論を保留する。公表用表は `SE / SD` と `Basis` を表示し、
保留中のSE・区間セルを空欄にする。技術CSVに値が残ることは、公表可能という意味ではない。
また、能力の区間と、次の評定の予測区間も別物である。後者には新しい評定の応答変動が加わる。

### 2. 事後SDとEAPの標本SEは、数値も異なる

難度0・識別力1が既知の二値項目1回、母集団N(0,1)を考える。
正答ならEAPは+0.413242、誤答なら−0.413242で、どちらの条件付き事後SDも0.910621となる。
真の能力を固定し、2通りの回答をその応答確率で平均すると、次の量をモンテカルロなしで計算できる。

| 固定した真の能力 | EAPの標本SD（標本SE） | EAPのバイアス | EAPのRMSE | 条件付き事後SD |
|---|---:|---:|---:|---:|
| 0 | 0.413242 | 0 | 0.413242 | 0.910621 |
| 2 | 0.267803 | −1.685277 | 1.706423 | 0.910621 |
| 3 | 0.175668 | −2.625955 | 2.631824 | 0.910621 |

強い縮小では推定量の反復ばらつきが小さくても、真値からの誤差は大きくなり得る。
したがって、標本SEが小さい方を単純に「精度が高い」と選ばない。
ここでの0.910621を0.413242に置き換える修正も、対象の異なる量への置換になってしまう。

この例の正答時の95%等裾事後信用区間は約[−1.365260, 2.211439]、
誤答時は[−2.211439, 1.365260]である。各区間の事後確率は95%だが、
真の能力を0に固定した反復では両方の区間が0を含み、3に固定した反復では両方とも3を含まない。
能力を仮定したN(0,1)からも抽出して平均すると被覆は95%になることを独立な積分で確認した。
**事後確率95%、真値ごとの反復被覆95%、仮定した母集団で平均した被覆95%は異なる条件である。**
これは二値1回答という既知モデルの数学的説明であり、現行MFRMの被覆率を測定した結果ではない。

### 3. 校正誤差を含めると、0を超える判断が変わる小例

仕組みを分離するため、Raschではなく解析解のある正規モデルを使用した。
`y = theta − b + epsilon`、`theta ~ N(0,1)`、外部校正からのずれを表す
`b ~ N(0,0.09)`、`epsilon ~ N(0,0.04)` とし、条件付け前には独立、観測値を `y=0.6` とした。
分散0.09は実データから得たSEではなく、説明用に指定した値である。

| 扱い | 事後平均 | 事後SD | 95%事後信用区間 |
|---|---:|---:|---|
| bを0に固定 | 0.576923 | 0.196116 | [0.192543, 0.961304] |
| bも共同事後分布で積分 | 0.530973 | 0.339182 | [−0.133811, 1.195757] |

校正誤差を含めた結果、0をまたぐかどうかが変わる。中心も変わっており、区間の幅だけを足す処理ではない。
計算は共同精度行列の逆行列と、観測値に条件付ける別の正規分布公式で照合した。

一般に、整合した共同事後分布の下では、全分散の公式は次の形になる。

\[
\operatorname{Var}(\theta\mid D)
=E_{\psi\mid D}\{\operatorname{Var}(\theta\mid D,\psi)\}
+\operatorname{Var}_{\psi\mid D}\{E(\theta\mid D,\psi)\}.
\]

右辺は**校正パラメータの共同事後分布に関する平均**である。
最初の項を校正点推定値での事後分散へ置き換え、外部SEの二乗をそのまま足せばよい、という公式ではない。
上の例では完全な事後分散は0.115044だが、固定校正時の分散に0.09を単純加算すると0.128462になる。
同じデータから校正・得点を推定する場合には、依存関係やデータの二重利用にも注意する。
校正誤差を含めた区間が、どのプラグイン区間よりも必ず広いという一般則にもならない。

### 4. 共通校正の誤差は、個人の差では相殺する場合がある

同じ正規モデルで、2人が共通のbを使い、観測値を0.6と0.1とする。
校正を積分した各人の事後SDは0.330749、2人間の事後共分散は0.070933となった。

\[
\operatorname{Var}(\theta_1-\theta_2\mid D)
=V_{11}+V_{22}-2V_{12}.
\]

差の事後SDは **0.277350**。共分散を無視して各人の分散を足すと **0.467749** になる。
この例では共通の位置ずれが差から消えるため、差のSDは校正固定の場合と一致する。
異なる校正、異なる評価者、異なる負荷の誤差では同じ相殺を仮定できない。
一般の共分散の符号によって、無視した影響の向きも変わる。
個々の区間の重なりから差の有意性や順位確定を判定する方法も避ける。

### 5. TAMのSEを比較基準にする際の注意

インストール版TAM 4.3.25を使った既存の二値2項目・100人・固定母集団の対照を再利用し、
同一点の情報行列から計算を再確認した。

| SEの計算法 | 項目1 | 項目2 |
|---|---:|---:|
| TAMの通常出力 `se.xsi` | 0.238644 | 0.224890 |
| TAMの追加計算 `tam.se` | 0.256436 | 0.243422 |
| 全観測情報行列の逆行列からのSE | 0.259840 | 0.246654 |

この例の `tam.se` は `1/sqrt(I_jj)` と一致し、`sqrt((I^{-1})_jj)` とは異なる。
ここでのIは能力を積分した周辺尤度の観測情報であり、その上で他の構造座標を固定した曲率と、
他の構造座標も未知とする共同計算を区別している。
公式仕様にも、`tam.se` はパラメータ間共分散を無視し、分散・共分散のSEは未実装と記されている。
[TAM公式SE仕様](https://alexanderrobitzsch.github.io/TAM/reference/tam.se.html)

正定値の情報行列を対象座標bと他の未知座標etaに分けると、共同共分散のb部分は
`(I_bb − I_b,eta I_eta,eta^{-1} I_eta,b)^{-1}` となる。
単なる `I_bb^{-1}` と一致するには追加条件が必要である。
自由SD・自由識別力などを推定したのに、その座標との交差項を除いた逆行列だけを使わない。
また、TAMのWLE/MLEのSEを、PythonのEAP事後SDと列名だけで比較しない。
[TAM公式WLE/MLE仕様](https://alexanderrobitzsch.github.io/TAM/reference/tam.wle.html)

### 6. 逆行列を作れることと、SEが存在することは別

現在の `_invert_information_matrix` は小さい固有値や負の固有値を閾値まで引き上げ、有限の行列を返す。
人工的な情報行列 `diag(1,0)` と `diag(1,−0.01)` を入れると、どちらも第2座標の対角平方根は**8192**になる。
これは `sqrt(machine epsilon)` に基づく床の結果であり、データから精度を推定できた証拠ではない。
零固有値は識別不能等、負の固有値は停留点・曲率・数値計算等の問題を疑う理由になる。

この対照では正の部分だけの条件数は1だったため、小さい条件数だけでも安全とは判定できない。
元の最小固有値、階数欠損、床を使った数、停留性、境界を併せて確認する。
現行の出力資格は正則化した共分散を保留し、全階数でも技術値として区間被覆率の確認と区別する。
これらの保留と、MML全体の推論保留を維持する。

### 7. CI手法を選ぶ前に定めること

| 方法 | 検証すべき対象・限界 |
|---|---|
| 全観測情報によるWald／デルタ法 | 同定した自由座標、全未知パラメータ、連続積分、局所曲率、内部性、変換。境界や歪みで対称区間をそのまま使わない |
| プロファイル尤度 | 対象値ごとに他の未知量を再最適化し、積分も点検する。通常の尤度比カイ二乗近似を使えるかは別の条件 |
| パラメトリックブートストラップ | データをどのモデル・割付で生成し、何を固定／再推定するかを決める。モデル誤指定まで自動で解決しない |
| ノンパラメトリック／クラスター再標本化 | 人・課題・評価者のどれを母集団へ一般化するか決める。人物単位だけでは評価者の母集団変動を含めない。交差割付と接続を点検する |
| 共同ベイズ事後分布 | 校正・母集団・個人を含む整合したモデル、事前分布、同定、計算精度を検証する。事後信用区間を自動的に頻度論的CIと呼ばない |
| サンドイッチ等の頑健共分散 | 推定方程式、依存単位、独立クラスター数を確かめる。識別不能や少数クラスター、校正固定の問題を万能に解消しない |

既存のG理論の人物クラスター再標本化と、固定した残差行列のPCA再標本化は対象が異なる。
どちらも通常のMFRM校正を全て再推定するブートストラップSEの検証済み実装ではない。
再標本化時の重複人物はコピーごとにIDを分け、接続切れ・空カテゴリー・推定失敗を記録するなど、

### 3. 試作した計算法

対象は、**単一の正規母集団・1次元・固定校正・能力に対して線形なカテゴリーロジット**に限定した。

1. 対数事後密度の微分から最頻点を求め、そこでの曲率から局所的な幅を求める。
2. その中心・幅を使う座標で、最頻点を明示した適応積分を行う。正規近似の分布へ置き換えるのではなく、

4. 超過確率は基準から上側を直接積分する。分位点はCDFまたは上側確率の根を区間内で探索する。

### 6. 開発方針への含意

1. **判断に使う量を先に決める。** EAP、中央値、下側分位点、超過確率、評価者差、Infitでは必要な検証が異なる。
   比較演算子、損失、保留時の追加評定や人による確認を、結果を見る前に定める。
2. **判定量そのものを独立計算する。** 片側確率は基準で分けた連続積分、分位点はそのCDFの逆算を候補とする。
   密度が小さい場所では小さいCDF誤差が大きい分位点誤差になるため、尤度・平均だけの精度基準を流用しない。
   積分器の誤差出力は厳密な上界とは限らない（[SciPy `quad`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.quad.html)）。
3. **再積分、再校正、モデル感度を別々に記録する。** 数値経路で規則の結論が割れた場合は保留する。
   全経路が同じ側でも正しさの証明ではない。保証された誤差上界 `delta` がある場合に限り、
   `g_hat − delta > c` 等で数値上の方向を保証できる。この保証にも標本・モデル不確実性は含まれない。
4. **TAMは独立対照として使い、判定契約を共通にする。** モデル・得点法・区間・重みを揃えた上で、
   両者を独立な積分基準とも比較する。TAMを正解とみなしてPythonの既定値だけ寄せる方針は採らない。

今回の優先課題は、全推定器の交換よりも、現在の分位点をどの精度で解釈できるかの確認と、
意思決定に必要なCDF・分位点の精度要件の明文化である。連続CDFの新しい公開機能は実装していない。
校正誤差・標本抽出・モデル不適合の検証が済むまで、既存MMLの推論保留を維持する。

### 共通する推定対象

単位重みでは、両者のMMLは次の個人単位の周辺対数尤度を対象にする。

\[
\ell(\psi)=\sum_p\log\int
\prod_{i\in O_p}P(X_{pi}=x_{pi}\mid\theta,\psi)
\phi(\theta;\mu_p,\sigma^2)\,d\theta.
\]

能力を積分して項目・ファセット等を推定し、その校正値の下で個人の事後分布を計算する。
E-stepでは「その個人の回答を条件とする積分点の重み」を求め、M-stepではその重みに基づいて
構造パラメータを更新する。Pythonの直接最適化も、同じ設定ならこの周辺尤度を対象にし、
その勾配に事後重みを使う。直接最適化にしただけで別の統計モデルになるわけではない。

対応が必要なのは入力、観測された行、カテゴリー、確率式、符号、同定制約、母集団、
重み、罰則である。PCM/RSMと識別力固定のGPCMの照合を、自由識別力・自由SD・回帰・アンカーへ
自動で拡張しない。TAMのA/B/Eと推定法の範囲は[公式モデル仕様](https://alexanderrobitzsch.github.io/TAM/reference/tam.mml.html)を参照。

### 自由SDで特に違う点

通常のTAMの固定θグリッドでは、正規密度のlog(SD)の得点に事後平均
`E[(theta-mu)^2 / sigma^2 - 1 | responses]` が現れる。
Pythonの有限GH則は、重みを固定して点 `theta=mu+sigma*z` を動かすため、log(SD)微分は
各点の応答尤度の微分を通じて計算する。連続積分では同じ対象の表現を変えたものだが、
有限点では同じ得点とは限らない。既存Pythonのモーメント更新を、有限GH目的関数の厳密な最大化と扱わない。
Joint経路の勾配が小さくても、連続積分への近似誤差が小さいことは別途確認する。

二値2項目・100人・固定N(0,1)の小例で、初期値0からTAMを最大1反復で止めたところ、

## TAMとの関係と現行Pythonの点検 — 2026-10-23

**推奨は、既存Pythonを維持し、同じモデルを表現できる範囲でTAMを独立した比較対象にすること。**

### 選択肢と判断

| 方針 | 利点 | 負担・限界 | 採用する条件 |
|---|---|---|---|

どちらが高速か、配布にどれだけ手間がかかるかは今回測っていない。速度差を採用理由にはしない。
新しいPython推定器を一から作る案は、既存の検証資産を再構築する負担があり、現段階では勧めない。

### 揃えるべき数理と、揃えてはいけない表示上の一致

現行GPCMの隣接カテゴリー対数オッズは概念的に
`log(P_k/P_{k-1}) = a_c * (theta + sum_f sign_f * effect_f - step_ck)`
であり、識別力が能力だけでなくファセット効果と段階にも掛かる。
TAMの一般式 `P_k ∝ exp(B_k * theta + A_k * xsi)` へは、識別力を固定すればA/B両方に組み込める。
識別力を推定する場合、Aも識別力に依存するため、固定Aのまま傾きだけ推定する設定と
現行の共有効果モデルは一般には同じにならない。
TAMには `tam.mml.2pl` と `GPCM.design` があり、「TAMは識別力を推定できない」という意味ではない。
多ファセット関数・傾きデザイン・尺度制約を含めて対応を確認する必要がある。
出典：[TAMのモデル・A/B/Eの公式仕様](https://alexanderrobitzsch.github.io/TAM/reference/tam.mml.html)。

MMLは個人ごとの周辺尤度を積み上げる。比較には、入力行・欠測・カテゴリー・正負の符号・
同定制約・母集団分布・重み・積分・EAP等の得点法を揃える。JMLEとTAMのMMLは異なる推定法であり、
推定値の一致を要求しない。回答ごとの重みをTAMの個人重みへそのまま置き換えない。

SEは列名で揃えない。座標ごとの曲率からの `1/sqrt(I_jj)` と、他の推定パラメータとの結合を
含む `sqrt((I^{-1})_jj)` は一般に異なる。EMのQ関数の曲率と、欠測情報の補正を含む
周辺尤度の観測情報も区別する。TAMの `tam.se` は共分散を無視する計算で、分散・共分散のSEは
未実装、`GPCM.design` の傾きSEは実験的と明記されている。
出典：[TAMのSEの公式仕様](https://alexanderrobitzsch.github.io/TAM/reference/tam.se.html)。

## GPCMとTAM：確率式の対応と再推定の境界 — 2026-10-14

**識別力を含む確率式はTAMへ対応づけられ、9条件の同一点計算が許容差内で一致した。**
ただし、TAMで単にGPCMを指定するだけでは、現行アプリと同じ推定問題になるとは限らない。
識別力は、能力に応じて回答確率が変わる度合いを表す。現行アプリでは識別力が
ファセット効果と段階にも掛かるため、識別力の推定中にこの関係を保つ必要がある。

### 何を対応づけたか

今回の入力では、評価者・課題・観点の効果をそれぞれ \(r_r,t_t,d_c\)、
観点別の識別力を \(a_c\)、段階を \(\tau_{ch}\) とすると、カテゴリー \(k\) の確率は
次の \(\ell_{ik}\) の指数をカテゴリー0〜3の合計で正規化した値である。

\[
\ell_{ik}=a_c\left[k(\theta-r_r-t_t-d_c)-\sum_{h=1}^{k}\tau_{ch}\right].
\]

**能力だけに識別力を掛ける式とは異なる。** この違いは言語の違いではなく、モデルの指定にある。
一方、制約のない項目別の切片なら、識別力を切片へ吸収する座標変換で同じ確率を表せる場合がある。
今回の論点は、複数の観点で共有する評価者・課題効果と識別力の関係まで、その変換で維持できるかである。

[TAM 4.3-25の公式説明](https://cran.r-project.org/web/packages/TAM/refman/TAM.html)の確率式は
\(B_{ik}\theta+A_{ik}\xi\) を用いる。識別力を掛ける前のファセット・段階の係数行列を \(D\)、

\(1/\sqrt{I_{jj}}\) と、同時推定の不確実性を含む \(\sqrt{(I^{-1})_{jj}}\) は一般に異なる。
自由SDでは構造パラメータとSDとの交差項も必要になる。

既存の[二項目・固定分散対照](../validation/tam_se_definition_check.R)も今回再実行し、
`tam.se()` と独立な対角曲率SEの最大差1.93e−9、共同SEとの差0.003405を再現した。

## 共通の積分と、異なる数値近似

単位重み・一つの潜在能力を持つ比較可能なモデルでは、Personごとの反応ベクトルをまとめて

\[
\ell(\alpha,\beta,\sigma)
=\sum_p\log\int_{-\infty}^{\infty}
\underbrace{\prod_{j\in O_p}P(Y_{pj}=y_{pj}\mid\theta,\alpha)}_{L_p(\theta;\alpha)}
\frac1\sigma\phi\!\left(\frac{\theta-\mu_p}{\sigma}\right)d\theta,
\qquad \mu_p=X_p\beta
\]

を最大化する。`alpha` はファセット効果・ステップなど。欠測は観測集合 `O_p` から外す。
評定行ごとに積分してから積を取る式とは異なり、同じPersonの能力を共有する。
行内の反応重みと積分外のPerson重みも同じ操作ではないため、重み付き比較は別途対応を決める。

標準正規Gauss–Hermite（GH）の点 `z_q` と重み `w_q` なら、

\[
\ell_Q=\sum_p\log\sum_{q=1}^Q w_q L_p(\mu_p+\sigma z_q;\alpha).
\]

変数変換により正規密度とJacobianは重みに含まれる。ここで `dnorm` や `1/sigma` を
もう一度掛けると二重計上になる。積の過小化を防ぐ計算では、カテゴリーの対数確率を
Person内で足し、`log(w_q)` を加えてから `logsumexp` を取る。

| 対象 | 今回確認した求積 | 最適化・母集団の扱い |
|---|---|---|
| Python | `hermgauss` を標準正規へ変換し、点を `sigma` 倍。低水準API既定15点、前回の開発監査は31・61点 | 現行の自由SD経路はEM。共同停留性を確認するv2は開発用。母集団SDが動くと点も動く |
| mfrmr 0.2.4開発版 | Golub–Welschの固有値・固有ベクトルから標準正規GHを生成。公開 `fit_mfrm()` 既定31点 | 既定 `direct` は勾配法と必要時のpolishing。通常RSM/PCMは固定N(0,1)、母集団モデル有効時は `mu_p + sigma*z_q`。限定したEM・hybridもある |
| TAM 4.3.25の決定論的経路 | 既定 `nodes=seq(-6,6,len=21), snodes=0`。保存比較では31・61点等を明示した等間隔グリッド | 固定点で正規密度を評価するEM系。母集団平均・分散を固定するか推定するかを明示する |
| ConQuest | `gauss` はGH、`quadrature` は別方式。回帰変数なしでは前者、回帰変数ありでは後者が既定。保存比較は **`method=quadrature` を明示** | MMLはEM系。今回の記録から既定 `gauss` の結果まで検証済みとは扱えない |

TAMは `snodes>0` ならQMC、さらに `QMC=FALSE` なら通常のMonte Carloを選べる。
ConQuestの `quadrature` は点数と `minnode/maxnode` を持ち、既定範囲は−6～6、
`gauss` ではこの範囲指定は無視される。公式の呼び名が同じ「Gaussian quadrature」でも、
TAMの既定等間隔点をHermite多項式の根と同一視しない。
[TAM公式マニュアル](https://alexanderrobitzsch.r-universe.dev/TAM/doc/manual.html)、
[ConQuest公式コマンド参照](https://conquestmanual.acer.org/s4-00.html#estimate)

実機のTAM `tam.mml` → `tam_stud_prior(normalize=FALSE)` → `tam_calc_posterior` →
`tam_mml_compute_deviance` を追うと、1次元の決定論的経路の周辺確率は
`Delta * sum_q L_p(t_q) * dnorm(t_q, mu_p, sigma)` として評価される。
事後確率の行正規化と、事前密度をグリッド上で総和1に再正規化する処理は区別する。
後者を無断で追加すると、有限グリッドの母集団パラメータ依存の目的関数を変え得る。

mfrmrのGHは母集団の位置・尺度へ変換するが、Personの**事後モード・曲率に合わせる
適応的GHではない**。ファセットが複数あっても現在のモデルの積分は1次元である。
多次元化した場合の積分点数の増大を、ファセット数の増加と混同しない。

## 今回実行した求積関数の照合

Pythonの `gauss_hermite_normal` はASTから当該関数だけを、mfrmrはRの `parse()` から
同名関数の代入式だけを取り出して実行した。アプリの推定やインストール済み旧Rパッケージは使っていない。

| 61 | 5.33e−14 | 5.27e−15 | 4 |
| 121 | 5.68e−14 | 5.79e−15 | 36 |

**新しく確認した注意点：微小重みのゼロと保存校正の要件が整合していない。**
Rの現在の固有ベクトル方式では、Q61の4点で重みが正の微小値からゼロになる。
対応するNumPy側重みの合計は約7.42e−37で、Q121・Q181でも約2.18e−36・2.47e−37。
通常の単位重みの反応尤度積は0～1なので、これらの項を落とす効果は絶対確率では小さい。
しかし非常に小さい周辺確率に対する相対誤差・対数尤度誤差は、この値だけでは保証できない。
この観測は過去のTAM差やPythonの停留性問題の原因を特定したものではない。

加えて、mfrmrの保存校正は生成した重みをそのまま格納する一方、検証時は
`any(weights <= 0)` を拒否する。Q61・121・181の今回生成した重みはこの述語に抵触し、
Q31は通った。**fit時の点数を増やすことと、保存校正のscoring点数を増やすことは別**である。
これは生成関数と検証条件の直接照合であり、保存校正API一式の新規実行試験ではない。
根拠: [生成・格納・検証](../../mfrmr/development/R/core-fixed-calibration.R)、
[GH生成関数](../../mfrmr/development/R/mfrm_core.R)。
対応時は重みを任意の小数に置き換えず、共通生成関数の数値安定性と高次数の回帰検査を検討する。
今回mfrmrには変更を加えていない。

## 0.2.4で実装済みの対応と、Python側への含意

mfrmrの [修正記録](../../mfrmr/development/inst/validation/mml-quadrature-remedy-record-0.2.4.md)
と現在の [公開API](../../mfrmr/development/R/api-quadrature-sensitivity.R) を照合した。
`mml_quadrature_sensitivity()` はRSM・PCM・限定GPCMについて、同じデータ・モデルの再推定から
尤度、構造パラメータ、確率、EAP、事後SD等の変化を示す。既定 `c(31,41)` は比較の出発点であり、
十分な精度の宣言ではない。自動の安定性閾値を持たず、推論資格も昇格させない。

[保存校正の抽出](../../mfrmr/development/R/api-calibration.R) はこのreviewと、その中の
厳密に同じ最高次数fitを要求する。これは確認手順の強制であり、数値安定性の自動認定ではない。
推定と得点計算の積分は別に評価する設計になっており、現在のscoring既定は31点である。

母集団分散の座標も対応させる必要がある。mfrmrは `zeta=log(sigma^2)`、Python v2は
`eta=log(sigma)` を使うため、`zeta=2*eta`。同じ他パラメータ座標ならスコアは
`d ell / d eta = 2 * d ell / d zeta` となり、Hessianにも変換が必要である。
mfrmrの感度出力のSD標準誤差は、共同共分散の該当成分から
`0.5*sigma*sqrt(Var(zeta))` を計算する診断値である。正則化状態も記録され、公開SE資格を
上書きしない。Pythonで撤去した「他パラメータ固定の曲率をProfile SEと呼ぶ」計算とは区別する。

Python側の次の作業は、既存v2・R照合・感度アダプターを再利用し、次の順に限定する。

1. **同じ有限求積目的関数での停留性**：構造効果とSDを同時に検査する。
   SD依存の移動点を含めて微分し、EMの終了だけでは合格にしない。
2. **積分精度**：既存Q31/Q61開発確認を出発点に、同じデータで尤度・確率・EAP・事後SD・
   母集団SDの変化を調べる。TAMは範囲と密度、GHは次数と微小重みを記録する。
   高次数の相互一致だけで十分とせず、必要な条件では監査した連続積分も使う。
3. **独立実装と推論**：同定・切片・平均・分散・ステップ・カテゴリー支持・重み・
   尤度定数を対応させる。EAP同士を比較し、WLEとは分ける。SE・区間・被覆率は別ゲートに残す。
4. **高速化とUI**：上記を保存した上でJAXを評価する。画面では「推定の終了」「積分点を
   変えた結果の動き」「推論に使える範囲」を順に示し、推定と得点計算の点数を区別する。

前回のPython RSM/PCMのQ31/Q61検査は、ゆるい開発用条件での確認であり、今回のmfrmrの
証拠を引用して本番資格に昇格させない。JAXの高速化は高精度の積分を実行しやすくする候補であり、
求積誤差を自動的に消すものではない。NumPyroの導入もこのMML検査の前提ではない。

2026-09-12の後続作業として、[Pythonと独立R計算の開発照合](mml_cross_language_development_check.md)
を実行した。既存の24 Person例で同一点の尤度・勾配・得点を比較し、Q121/Q181と
連続積分を追加した。これは本レビュー後の新規開発結果であり、外部ソフト全般の同等性や
mfrmrのゼロ重み問題の修正を宣言するものではない。
