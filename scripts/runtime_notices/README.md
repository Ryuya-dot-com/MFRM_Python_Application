# Tcl/Tk notices for the Windows build

These unmodified notices accompany Tcl/Tk 8.6.15 in CPython 3.14.3 for Windows.
The Windows installer does not install separate `license.terms` files in its
`tcl/tcl8.6` and `tcl/tk8.6` directories. macOS builds use their installed notices.

- Version definition: https://github.com/python/cpython/blob/v3.14.3/PCbuild/tcltk.props
- Tcl source: https://github.com/python/cpython-source-deps/blob/tcl-core-8.6.15.0/license.terms
- Tk source: https://github.com/python/cpython-source-deps/blob/tk-8.6.15.0/license.terms

Recheck these notices when changing the bundled Python or Tcl/Tk version.
